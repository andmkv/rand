# Glossary

**Alias** — The name of a personal sprite or sound in code, starting with `@`, such as `@hero`.

**Argument** — A value given to a command or function: in `CIRCLE 128,96,30`, the three numbers are arguments.

**Assignment** — Storing a value in a variable: `SCORE = 0`.

**Asset** — A picture or a sound that a program uses: built-in ones, or your own.

**BASIC** — "Beginner's All-purpose Symbolic Instruction Code": a family of easy programming languages from the 1960s onward. Randomize USR's language is BASIC-like, with its own commands.

**Beat** — The unit of musical time. `TEMPO` sets how many beats fit in a minute.

**Block** — A group of statements that belong together: the body of a `FOR`, `IF` or `DO`.

**Blocking** — A command that makes the program wait before the next line, such as `WAIT`, `BEEP` or `SOUND`.

**Border** — The coloured frame around SCREEN (`BORDER`).

**Bug** — A mistake in a program. Finding and fixing bugs is *debugging*.

**Checkpoint** — A saved version in a cloud project's history.

**CODE** — The part of the editor where you type your program.

**Command** — An instruction at the start of a line: `PLOT`, `INK`, `SFX`.

**Condition** — A yes/no question used by `IF`: `SCORE > 5`.

**Coordinates** — A pair of numbers, `x,y`, naming a pixel on SCREEN.

**Cooperative** — Describes a program that regularly gives time back to the browser, so STOP always works.

**Demo** — A temporary account-like session for trying cloud features. Nothing in it is kept.

**Drawing layer** — The picture made by drawing commands. Sprites float above it.

**Envelope** — The shape of a sound's loudness over time: Attack, Decay, Sustain, Release.

**Frame** — One picture in a series; also one step of a game loop (`FRAME`).

**Function** — A command that gives back a value: `RND(1,6)`. Use it inside an expression.

**Game loop** — A `DO … LOOP` that reads keys, updates the world, draws, and calls `FRAME`.

**Guest** — Someone using Randomize USR without an account.

**Hit box** — The rectangle `HIT` uses for a sprite: its `WIDTH` × `HEIGHT`.

**INK / PAPER** — The colour of drawing, and the colour of the empty background.

**Instrument** — A saved sound that can play any note, used as the last argument of `NOTE` or `PLAY`.

**Inventory** — The drawer that shows everything you can use: sprites and sounds.

**Loop** — A block that repeats: `FOR … NEXT` counts, `DO … LOOP` goes on forever.

**Method** — An order to a sprite, written after a dot: `CAT.MOVE 10,20`.

**Palette** — The sixteen colours of SCREEN.

**Pinned** — Fixed to one exact saved version. A published project is pinned.

**Pixel** — One tiny coloured square. SCREEN is 256 × 192 of them.

**Property** — A fact about a sprite, read after a dot: `CAT.X`.

**`.randusr`** — The file format for saving a project to your computer.

**Remix** — A private copy of someone's published project that you can change.

**Sandbox** — The free-play mode of the editor.

**SCREEN** — The 256 × 192 picture.

**SFX** — A sound effect, or the command that plays one without waiting.

**Spellbook** — The in-app quick reference for commands (called *spells* in the story).

**Sprite** — A movable picture object created with `SPAWN`.

**State** — Which situation a game is in: getting ready, playing, won, lost. Usually a variable called `STATE`.

**Statement** — One line of a program.

**Story** — The guided adventure mode of the editor.

**String** — Text in quotation marks: `"hello"`.

**Tempo** — The speed of music, in beats per minute.

**Transparent** — A pixel of a sprite that lets the background show through.

**Variable** — A name that holds a value.
