# Not available yet

This handbook describes what Randomize USR does today. A few things are *not* available, and to avoid giving you code that does not work, they are not taught here. There are no commands for them to learn.

## Music Tracker

A Music Tracker (a pattern-based editor for songs) has been discussed and is **postponed**. It is not part of the app and there is no tutorial and no tracker commands. For music today, use `NOTE`, `REST`, `TEMPO` and `PLAY` ([the sound chapter](book:sound)), and instruments made in the [Sound Lab](book:sound-lab).

## Sharing assets on their own

Sprites and sounds travel *inside* projects. Publishing or sharing a sprite library by itself, asset folders and remixing a single asset are not available.

## More example games

The EXAMPLES drawer contains the games described in [chapter 14](book:reading-real-games). Other game ideas that may exist outside the app are not part of this handbook.

## This handbook

The handbook is a set of Markdown files in the project's `book` folder. Anyone can improve it by editing those files. Every program in it is run automatically against the real BASIC engine, so a new example must work before it can be published. How to contribute is described in `book/README.md`.
