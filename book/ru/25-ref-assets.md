# Справочник: спрайты и звуки, которые идут с машиной

## Встроенные спрайты

Используй идентификатор в `SPAWN("id",x,y)`. Регистр в идентификаторах не важен. Вкладка **ИНВЕНТАРЬ** показывает каждую картинку и вставляет код за тебя. Эти картинки — оригинальная графика 8 × 8 пикселей, показанная как 16 × 16.

| id | Картинка |
| --- | --- |
| `cat` | кот |
| `wizard` | волшебник в остроконечной шляпе |
| `ghost` | дружелюбное привидение |
| `key` | ключ |
| `door` | дверь |
| `star` | звезда |
| `crate` | деревянный ящик |
| `dynamite` | динамитная шашка |
| `rocket` | ракета |
| `slime` | слизень |
| `alien` | пришелец |
| `ship` | космический корабль |
| `paddle` | ракетка для игр с мячом |
| `ball` | мяч |
| `brick_red` | красный кирпич |
| `brick_cyan` | голубой кирпич |
| `brick_yellow` | жёлтый кирпич |
| `platform` | платформа |
| `traveler` | маленький герой |

```basic id=r-all-sprites sprites=19
KINDS = LIST("cat","wizard","ghost","key","door","star","crate","dynamite","rocket","slime")
PUSH KINDS,"alien"
PUSH KINDS,"ship"
PUSH KINDS,"paddle"
PUSH KINDS,"ball"
PUSH KINDS,"brick_red"
PUSH KINDS,"brick_cyan"
PUSH KINDS,"brick_yellow"
PUSH KINDS,"platform"
PUSH KINDS,"traveler"
FOR I = 1 TO COUNT(KINDS)
  S = SPAWN(ITEM(KINDS,I),10 + I * 12,90)
NEXT I
```

## Встроенные звуки

Используй идентификатор в `SOUND "id"` или `SFX "id"`. Послушать их можно в ИНВЕНТАРЕ кнопкой **▶ Слушать**.

| id | Звучит как | Волна | Скольжение высоты | Длительность |
| --- | --- | --- | --- | --- |
| `explosion` | взрыв | шум | 140 → 30 Гц | 0,56 с |
| `coin` | сверкающая награда | квадрат | 880 → 1760 Гц | 0,18 с |
| `laser` | космический выстрел | пила | 1600 → 80 Гц | 0,22 с |
| `jump` | пружина | квадрат | 180 → 720 Гц | 0,20 с |
| `power-up` | растущий заряд | треугольник | 260 → 980 Гц | 0,50 с |
| `blip` | короткое касание | импульс | 740 Гц ровно | 0,12 с |
| `drum` | удар барабана | шум | 160 → 50 Гц | 0,24 с |
| `wind` | порыв ветра | шум | 280 → 90 Гц | 0,85 с |

```basic id=r-all-sounds events=SFX
SFX "explosion"
SFX "coin"
SFX "laser"
SFX "jump"
SFX "power-up"
SFX "blip"
SFX "drum"
SFX "wind"
```

## Личные ресурсы и псевдонимы

Спрайты и звуки, которые ты создаёшь (с аккаунтом), получают **псевдоним**: `@`, затем строчная буква, а потом до 30 строчных букв, цифр, дефисов или подчёркиваний. Он строится из названия, которое ты даёшь, никогда не меняется при переименовании ресурса и уникален среди всех твоих спрайтов и звуков (`@hero`, `@hero-2`). Название без латинских букв превращается в `@sprite` (и для звуков тоже) с номером, если это имя занято.

| Что | Синтаксис |
| --- | --- |
| личный спрайт | `SPAWN("@hero",x,y)` |
| личный звуковой эффект | `SOUND "@zap"` или `SFX "@zap"` |
| личный инструмент | `NOTE "C4",1,"@pluck"` и `PLAY "C4 E4","@pluck"` |

Проект **несёт с собой** ресурсы, которые использует (в `assetManifest`), так что программа работает у гостей, на других компьютерах и на опубликованных страницах. Проект может нести до 16 спрайтов и 16 звуков, а манифест ограничен 512 КиБ.

## Ограничения личных ресурсов

| Что | Ограничение |
| --- | --- |
| размер спрайта | до 64 × 64 пикселей (4096), 15 цветов и прозрачный слот |
| анимация | до 32 кадров, 1–12 кадров в секунду, цикл включён или выключен |
| ресурсы в аккаунте | 64 (спрайты и звуки вместе), по 100 версий каждого, всего 5 МиБ |
| длительность эффекта | от 50 мс до 5 с |
| частота звука | от 30 до 4000 Гц |
