# Клавиатура: персонаж, которым ты управляешь

**Цель:** двигать персонажа клавишами, удерживать его внутри ЭКРАНА и стрелять ровно один раз за нажатие.

## Спрашиваем про клавишу

`KEY("имя")` — функция, которая отвечает `TRUE`, пока клавиша зажата, и `FALSE`, когда нет. Ты спрашиваешь её на каждом кадре внутри цикла.

Можно использовать имена `"LEFT"`, `"RIGHT"`, `"UP"`, `"DOWN"` (стрелки), `"SPACE"`, `"ENTER"`, одну букву `"A"`–`"Z"` или цифру `"0"`–`"9"`. Регистр не важен. Любое другое имя даёт ошибку со списком допустимых.

> [!IMPORTANT]
> Клавиши идут на **ЭКРАН**, а не в КОД. Когда ты нажимаешь **ЗАПУСК**, программа с `KEY` сама переводит фокус клавиатуры на ЭКРАН. Если щёлкнуть в КОДЕ, чтобы что-то поправить, клавиши снова пойдут в редактор; щёлкни по ЭКРАНУ, чтобы вернуть их игре. Сочетания с `Ctrl`, `⌘` или `Alt` игнорируются, так что горячие клавиши браузера продолжают работать.

Буквенные клавиши читаются по их **положению** на клавиатуре, а не по букве на них, так что `KEY("W")` работает и на русской, и на греческой раскладке.

## Игровой цикл

Почти у каждой игры один и тот же скелет:

```text
всё подготовить
DO
  прочитать клавиши
  изменить мир
  нарисовать мир
  FRAME
LOOP
```

Вот он с космическим кораблём, который ездит влево и вправо:

```basic id=c11-move endless wait=5 keys=RIGHT vars="PX>=240;PX<=243"
SHIP = SPAWN("ship",128,170)
DO
  IF KEY("LEFT") AND SHIP.X > 16 THEN
    SHIP.MOVE_BY -3,0
  END IF
  IF KEY("RIGHT") AND SHIP.X < 240 THEN
    SHIP.MOVE_BY 3,0
  END IF
  PX = SHIP.X
  FRAME
LOOP
```

Запусти, щёлкни по ЭКРАНУ, если стрелки ничего не делают, и рули.

- `FRAME` заставляет цикл крутиться примерно 60 раз в секунду.
- Проверка `SHIP.X > 16` — **забор**: она разрешает кораблю ехать влево, только пока он ещё внутри ЭКРАНА. Без забора корабль уедет за край и потеряется.
- Два отдельных `IF`, по одному на направление, значит, что при нажатых обеих клавишах движения гасят друг друга.

Если хочешь, чтобы корабль перестал двигаться, когда отпускаешь клавиши, — он уже так и делает: корабль едет, только пока клавиша зажата.

## Четыре направления и две раскладки

Поддержи стрелки и WASD одновременно, соединив две `KEY` через `OR`:

```basic id=c11-wasd endless wait=5 keys="RIGHT,DOWN" vars="PX=240;PY=176"
HERO = SPAWN("traveler",128,96)
DO
  IF (KEY("LEFT") OR KEY("A")) AND HERO.X > 16 THEN
    HERO.MOVE_BY -2,0
  END IF
  IF (KEY("RIGHT") OR KEY("D")) AND HERO.X < 240 THEN
    HERO.MOVE_BY 2,0
  END IF
  IF (KEY("UP") OR KEY("W")) AND HERO.Y > 16 THEN
    HERO.MOVE_BY 0,-2
  END IF
  IF (KEY("DOWN") OR KEY("S")) AND HERO.Y < 176 THEN
    HERO.MOVE_BY 0,2
  END IF
  PX = HERO.X
  PY = HERO.Y
  FRAME
LOOP
```

Если нажать две клавиши сразу, персонаж идёт по диагонали: оба `IF` на одном кадре истинны.

## Один раз за нажатие: приём «была ли зажата?»

Если стрелять на каждом кадре, пока зажат ПРОБЕЛ, экран заполнится пулями. Обычно нужен *один* выстрел за нажатие. Хитрость в том, чтобы запомнить, была ли клавиша уже нажата на **предыдущем** кадре:

```basic id=c11-fire endless wait=3 keys=SPACE vars="SHOTS=1"
HELD = FALSE
SHOTS = 0
DO
  IF KEY("SPACE") AND NOT HELD THEN
    SHOTS = SHOTS + 1
    SFX "laser"
  END IF
  HELD = KEY("SPACE")
  FRAME
LOOP
```

Выстрел происходит только на кадре, где ПРОБЕЛ нажат *и* `HELD` ложно. В конце каждого кадра `HELD` обновляется. Даже если держать клавишу десять секунд, засчитается одно нажатие. Так в *Пиксельном походе* нужно отпускать ПРОБЕЛ между прыжками.

Попроще — **перезарядка**: счётчик, который считает до нуля, прежде чем разрешить следующий выстрел.

```basic id=c11-cooldown endless wait=3 keys=SPACE vars="SHOTS>=5;SHOTS<=8"
WAIT_SHOT = 0
SHOTS = 0
DO
  IF WAIT_SHOT > 0 THEN
    WAIT_SHOT = WAIT_SHOT - 1
  END IF
  IF KEY("SPACE") AND WAIT_SHOT = 0 THEN
    SHOTS = SHOTS + 1
    WAIT_SHOT = 30
  END IF
  FRAME
LOOP
```

С перезарядкой в 30 кадров можно стрелять не чаще двух раз в секунду.

## Летящий выстрел

Пуля — это спрайт, который ты двигаешь сам. Прячь его, когда он не летит, и используй видимость как флаг «занят ли он?»:

```basic id=c11-shot endless wait=3 keys=SPACE vars="SY>=20"
SHIP = SPAWN("ship",128,170)
SHOT = SPAWN("ball",128,160)
SHOT.SIZE 4,8
SHOT.HIDE
DO
  IF KEY("SPACE") AND NOT SHOT.VISIBLE THEN
    SHOT.MOVE SHIP.X,160
    SHOT.SHOW
    SFX "laser"
  END IF
  IF SHOT.VISIBLE THEN
    SHOT.MOVE_BY 0,-5
    IF SHOT.Y < 20 THEN
      SHOT.HIDE
    END IF
  END IF
  SY = SHOT.Y
  FRAME
LOOP
```

Один спрайт используется для каждого выстрела. Так спрайтов остаётся мало, а код короткий.

## Попробуй

1. Поменяй скорость корабля с 3 на 5. Всё ещё удобно?
2. Сделай так, чтобы корабль «заворачивался»: вылетев за правый край, он появляется слева.
3. Сделай так, чтобы корабль стрелял и по `UP`, и по `SPACE`.

<details>
<summary>Подсказки и ответы</summary>

1. Большая скорость кажется быстрой, но целиться точно труднее. В играх обычно берут 2–4 пикселя за кадр.
2. Замени забор на `IF SHIP.X > 255 THEN SHIP.MOVE 0,170`, оформленный в несколько строк.
3. `IF (KEY("SPACE") OR KEY("UP")) AND NOT SHOT.VISIBLE THEN`.

## Что ты узнал

- `KEY("имя")` — это `TRUE`, пока клавиша нажата; игровой цикл читает клавиши, меняет мир, рисует и вызывает `FRAME`.
- «Заборы» удерживают персонажей внутри ЭКРАНА.
- Чтобы стрелять один раз, запоминай состояние клавиши с прошлого кадра или используй перезарядку.
