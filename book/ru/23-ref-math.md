# Справочник: числа

Все эти функции возвращают значение и должны использоваться внутри выражения (`X = ABS(Y)`), а не одиноко на строке.

### `RND` {#fn-rnd}

**Синтаксис:** `RND(от, до)` → случайное целое число от `от` до `до`, **включая оба конца**.

Оба аргумента должны быть целыми, и `до >= от`; иначе ошибка `range`.

### `RANDOM` {#fn-random}

**Синтаксис:** `RANDOM(от, до)` · точно то же, что `RND`.

```basic id=r-rnd vars="A>=1;A<=6;B=5"
A = RND(1,6)
B = RANDOM(5,5)
```

Каждый запуск даёт новую последовательность. У машины нет способа задать начальное значение, поэтому программа не может повторить тот же случайный запуск.

### `SIN` {#fn-sin}

**Синтаксис:** `SIN(угол)` · угол в **радианах** (полный оборот — около 6,2832). Результат от −1 до 1.

### `COS` {#fn-cos}

**Синтаксис:** `COS(угол)` · то же, но косинус.

Чтобы поставить что-то под углом `A` на расстоянии `R` от центра `(CX,CY)`, используй `CX + COS(A) * R` и `CY + SIN(A) * R`. Поскольку ось y направлена вниз, увеличение `A` идёт на ЭКРАНЕ по часовой стрелке.

```basic id=r-sincos output="0|1|1|0"
PRINT ROUND(SIN(0))
PRINT ROUND(COS(0))
PRINT ROUND(SIN(3.14159 / 2))
PRINT ROUND(COS(3.14159 / 2))
```

### `ABS` {#fn-abs}

**Синтаксис:** `ABS(x)` → `x` без знака.

### `ROUND` {#fn-round}

**Синтаксис:** `ROUND(x)` → ближайшее целое. Дробь ровно в половину идёт вверх (к большему числу): `ROUND(2.5)` — это 3, а `ROUND(-2.5)` — это −2.

```basic id=r-abs-round output="7|3|-2|4"
PRINT ABS(-7)
PRINT ROUND(2.5)
PRINT ROUND(-2.5)
PRINT ROUND(3.6)
```

Аргументы `SIN`, `COS`, `ABS` и `ROUND` должны быть числами (иначе ошибка `number`), и у каждой функции ровно один аргумент (иначе ошибка `args`).

## Приёмы только с этими функциями

Нет `MOD` (остаток), `INT` (отбросить дробь) и `SQR` (квадратный корень). Нужное можно собрать самому:

| Что нужно | Как написать |
| --- | --- |
| `N` чётное? | `N / 2 = ROUND(N / 2)` |
| целая часть положительного `X` | `ROUND(X - 0.5)` |
| расстояние точки от центра | сравнивай квадраты расстояний: `DX * DX + DY * DY < R * R` |
| случайный элемент списка | `ITEM(ИМЯ_СПИСКА,RND(1,COUNT(ИМЯ_СПИСКА)))` |

```basic id=r-tricks output="true|3|true"
N = 10
PRINT N / 2 = ROUND(N / 2)
PRINT ROUND(3.7 - 0.5)
DX = 3
DY = 4
PRINT DX * DX + DY * DY < 26
```
