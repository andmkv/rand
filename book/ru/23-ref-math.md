# Справочник: числа

Все эти функции возвращают значение и должны использоваться внутри выражения (`X = ABS(Y)`), а не одиноко на строке. `MOD` можно писать и между двумя числами, как `+` или `*`.

### `RND` {#fn-rnd}

**Синтаксис:** `RND(от, до)` → случайное целое число от `от` до `до`, **включая оба конца**.

Оба аргумента должны быть целыми, и `до >= от`; иначе ошибка `range`.

### `RANDOM` {#fn-random}

**Синтаксис:** `RANDOM(от, до)` · точно то же, что `RND`.

```basic id=r-rnd vars="A>=1;A<=6;B=5"
A = RND(1,6)
B = RANDOM(5,5)
```

Каждый запуск даёт новую последовательность. У машины нет способа задать начальное значение, поэтому программа не может повторить тот же случайный запуск.

### `SIN` {#fn-sin}

**Синтаксис:** `SIN(угол)` · угол в **радианах** (полный оборот — около 6,2832). Результат от −1 до 1.

### `COS` {#fn-cos}

**Синтаксис:** `COS(угол)` · то же, но косинус.

Чтобы поставить что-то под углом `A` на расстоянии `R` от центра `(CX,CY)`, используй `CX + COS(A) * R` и `CY + SIN(A) * R`. Поскольку ось y направлена вниз, увеличение `A` идёт на ЭКРАНЕ по часовой стрелке.

```basic id=r-sincos output="0|1|1|0"
PRINT ROUND(SIN(0))
PRINT ROUND(COS(0))
PRINT ROUND(SIN(3.14159 / 2))
PRINT ROUND(COS(3.14159 / 2))
```

### `ABS` {#fn-abs}

**Синтаксис:** `ABS(x)` → `x` без знака.

### `ROUND` {#fn-round}

**Синтаксис:** `ROUND(x)` → ближайшее целое. Дробь ровно в половину идёт вверх (к большему числу): `ROUND(2.5)` — это 3, а `ROUND(-2.5)` — это −2.

```basic id=r-abs-round output="7|3|-2|4"
PRINT ABS(-7)
PRINT ROUND(2.5)
PRINT ROUND(-2.5)
PRINT ROUND(3.6)
```

### `INT` {#fn-int}

**Синтаксис:** `INT(x)` → целое число, не большее `x`.

Дробная часть отбрасывается **вниз**: `INT(3.9)` — это 3, а `INT(-0.5)` — это −1 (не 0). `ROUND` идёт к *ближайшему* целому, а `INT` всегда вниз.

```basic id=r-int output="3|-1|5|4"
PRINT INT(3.9)
PRINT INT(-0.5)
PRINT INT(5)
PRINT INT(RND(40,49) / 10)
```

### `MIN` {#fn-min}

**Синтаксис:** `MIN(a, b)` → меньшее из двух чисел.

### `MAX` {#fn-max}

**Синтаксис:** `MAX(a, b)` → большее из двух чисел.

Обе функции принимают ровно два числа. Вместе они держат значение в границах: `X = MAX(10, MIN(X, 246))` не даст `X` стать меньше 10 или больше 246.

```basic id=r-min-max output="3|7|-2|246"
PRINT MIN(3,7)
PRINT MAX(3,7)
PRINT MIN(-1,-2)
X = 300
PRINT MAX(10, MIN(X, 246))
```

### `MOD` {#fn-mod}

**Синтаксис:** `a MOD b` · или `MOD(a, b)` → остаток от деления `a` на `b`.

`7 MOD 3` — это 1: в семёрке две тройки и ещё одна лишняя. Если `b` положительное, результат никогда не отрицательный, поэтому `-1 MOD 8` — это 7 (так узоры плавно идут через ноль). Дроби тоже работают: `5.5 MOD 2` — это 1.5. `MOD` на ноль — ошибка `zero`. Как оператор он связывает так же, как `*` и `/`: `2 + 7 MOD 4 * 2` — это 8.

Типичное применение: `N MOD 2 = 0` спрашивает «`N` чётное?», а `НОМЕР_КАДРА MOD 10 = 0` истинно «каждый 10-й раз».

```basic id=r-mod output="1|1|7|true|8"
PRINT 7 MOD 3
PRINT MOD(7,3)
PRINT -1 MOD 8
PRINT 10 MOD 2 = 0
PRINT 2 + 7 MOD 4 * 2
```

Аргументы всех этих функций должны быть числами (иначе ошибка `number`). У `SIN`, `COS`, `ABS`, `ROUND` и `INT` ровно один аргумент; у `MIN`, `MAX` и `MOD` — ровно два (иначе ошибка `args`).

## Приёмы с этими функциями

Нет `SQR` (квадратного корня). Нужное можно собрать из того, что есть:

| Что нужно | Как написать |
| --- | --- |
| `N` чётное? | `N MOD 2 = 0` |
| целая часть `X` | `INT(X)` |
| удержать `X` между 10 и 246 | `MAX(10, MIN(X, 246))` |
| по кругу: 0, 1, … 7, 0, 1, … | `N MOD 8` |
| расстояние точки от центра | сравнивай квадраты расстояний: `DX * DX + DY * DY < R * R` |
| случайный элемент списка | `ITEM(ИМЯ_СПИСКА,RND(1,COUNT(ИМЯ_СПИСКА)))` |

```basic id=r-tricks output="true|3|5|true"
N = 10
PRINT N MOD 2 = 0
PRINT INT(3.7)
PRINT 13 MOD 8
DX = 3
DY = 4
PRINT DX * DX + DY * DY < 26
```
