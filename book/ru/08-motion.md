# Движение и анимация

**Цель:** заставить что-нибудь плавно двигаться с постоянной скоростью, пока не нажмёшь СТОП.

## Анимация — это много маленьких изменений

Фильм — быстрая череда неподвижных кадров. Твоя программа делает то же самое: чуть-чуть меняет позицию, немного ждёт, меняет ещё. Если шаги маленькие и быстрые, глаз видит движение.

```basic id=c08-slide vars="CX=228" sprites=1
CAT = SPAWN("cat",20,110)
FOR X = 20 TO 230 STEP 4
  CAT.MOVE X,110
  WAIT 0.02
NEXT X
CX = CAT.X
```

Кот прыгает на 4 пикселя каждые 0,02 секунды, то есть на 200 пикселей в секунду.

## Скорость в переменной

Лучше, чем жёстко задавать шаг, завести **переменную скорости**. Тогда отскок — это просто смена знака:

```basic id=c08-bounce endless wait=5 vars="PX>=16;PX<=250"
CAT = SPAWN("cat",30,110)
SPEED = 3
DO
  CAT.MOVE_BY SPEED,0
  IF CAT.X > 240 THEN
    SPEED = -3
  END IF
  IF CAT.X < 16 THEN
    SPEED = 3
  END IF
  PX = CAT.X
  FRAME
LOOP
```

Вся анимация состоит из пяти идей:

1. **Позиция** (здесь это сам спрайт).
2. **Скорость** — на сколько двигаться за шаг.
3. **Цикл**, который на каждом шаге прибавляет скорость к позиции.
4. **Проверка** у краёв, которая разворачивает скорость.
5. Короткая **пауза**, чтобы каждый шаг был виден: `FRAME`.

## FRAME: ждём следующий кадр

`FRAME` ждёт следующего обновления экрана, примерно **1/60 секунды**. Цикл `DO` с `FRAME` внутри крутится примерно 60 раз в секунду, а это обычная скорость видеоигр.

Почему не просто `WAIT 0.016`? Это тоже сработало бы, но `FRAME` сообщает машине кое-что полезное: *«картинка целиком готова, меня можно не торопить».* Как только в программе где-нибудь есть `FRAME`, машина меняет настроение. Она перестаёт резать твоё рисование на мелкие порции и позволяет рисовать много фигур между двумя `FRAME`. Это идеально для игр, где на каждом шаге всё стирается и рисуется заново.

Используй `WAIT секунды`, когда нужно определённое время (пауза в секунду, медленная анимация). Используй `FRAME` для сердцебиения игрового цикла.

> [!TIP]
> В игровом цикле думай в **пикселях за кадр**. Скорость 3 при 60 кадрах в секунду — 180 пикселей в секунду, так что ЭКРАН пересекается чуть меньше чем за секунду.

## Гравитация: ускорение

Настоящие предметы при падении ускоряются. В коде это так: на каждом кадре прибавляй немного к скорости, а скорость — к позиции.

```basic id=c08-gravity endless wait=6 vars="Y>=0;Y<=190"
BALL = SPAWN("ball",128,20)
VY = 0
DO
  VY = VY + 0.4
  BALL.MOVE_BY 0,VY
  IF BALL.Y > 170 THEN
    BALL.MOVE 128,170
    VY = -VY * 0.8
  END IF
  Y = BALL.Y
  FRAME
LOOP
```

- `VY` — вертикальная скорость. Она растёт на 0,4 на каждом кадре (гравитация).
- Когда мяч доходит до пола на y = 170, его ставят обратно на пол, а скорость меняет знак и уменьшается до 80 %, так что каждый отскок ниже.

Замени `0.4` на `0.1` — получится Луна, а `0.8` на `0.95` — более прыгучий мяч.

## Круги: SIN и COS

Чтобы двигать что-то по кругу, используй тот же приём, что и для рисования круга: позиция = центр + (COS(угол), SIN(угол)) × радиус, а угол увеличивай на каждом кадре.

```basic id=c08-orbit px="198,96=15" sprites=1
SHIP = SPAWN("ship",128,96)
FOR A = 0 TO 6.28 STEP 0.05
  X = 128 + COS(A) * 70
  Y = 96 + SIN(A) * 70
  SHIP.MOVE X,Y
  PLOT X,Y
  FRAME
NEXT A
```

Корабль оставляет след из точек: `PLOT` остаётся в слое рисунка, а спрайт движется поверх. Работают оба слоя сразу.

## Анимация рисованием: стереть и нарисовать заново

Двигать можно и рисованием. Рисунки сами не двигаются, поэтому старую фигуру стирают (рисуют её цветом фона) и рисуют на новом месте:

```basic id=c08-ball-draw endless wait=3 vars="BX>=8;BX<=248"
BX = 20
DX = 4
DO
  INK 0
  FILLCIRCLE BX,96,8
  BX = BX + DX
  IF BX > 248 OR BX < 8 THEN
    DX = -DX
  END IF
  INK 6
  FILLCIRCLE BX,96,8
  FRAME
LOOP
```

Рисовать спрайты и двигать их обычно проще. Но «стереть и нарисовать заново» — правильный инструмент, когда нужно нарисовать то, что не спрайт: счёт, полоски, хвосты и лучи.

## Время и ограничения

- `WAIT` принимает от 0 до 30 секунд за один вызов.
- Долго работающая программа должна содержать `DO … LOOP`; остальные программы машина останавливает после 10 000 проходов циклов или двух минут. Полный список — в [главе 5](book:loops).
- Без `FRAME` и `WAIT` цикл всё равно автоматически нарезается на порции, чтобы страница не зависала, но скорость тогда непредсказуема. Всегда задавай темп анимации через `FRAME` или `WAIT`.

2. Сделай так, чтобы корабль на орбите менял скорость по ходу (подсказка: сделай `STEP` угла переменной).

## Что ты узнал

- Анимация = немного изменить, немного подождать, повторить.
- Переменная скорости и проверка у краёв дают отскок; прибавление к скорости даёт гравитацию.
- `FRAME` — сердцебиение игрового цикла (около 60 раз в секунду).
- `SIN` и `COS` двигают предметы по кругу.
