# Твоя первая законченная игра: STAR CATCHER

**Цель:** сделать настоящую законченную игру из кусочков, которые ты уже знаешь. Каждый шаг — это программа, которая запускается, так что можно остановиться на любом шаге, и у тебя всё равно будет во что играть.

**Игра:** с неба падают звёзды. Ты управляешь котом, двигая его влево и вправо, и ловишь их. Каждая пойманная звезда — очко, а чем больше счёт, тем быстрее они падают. Если три звезды долетят до земли, игра окончена. Поймай десять — и ты победил. Нажми R, чтобы сыграть снова.

> [!TIP]
> Щёлкни по ЭКРАНУ после нажатия ЗАПУСК, чтобы стрелки управляли игрой.

## Шаг 1 · Кот, который двигается

Начнём с того, что ты знаешь из [главы про клавиатуру](book:keyboard): персонаж, цикл и два забора.

```basic id=c13-step1 endless wait=4 keys=LEFT vars="PX>=16;PX<=240"
CAT = SPAWN("cat",128,170)
DO
  IF KEY("LEFT") AND CAT.X > 16 THEN
    CAT.MOVE_BY -4,0
  END IF
  IF KEY("RIGHT") AND CAT.X < 240 THEN
    CAT.MOVE_BY 4,0
  END IF
  PX = CAT.X
  FRAME
LOOP
```

Переменная `PX` нужна только для того, чтобы проверка этого руководства могла посмотреть на позицию. Её можно удалить.

## Шаг 2 · Падающая звезда

Второй спрайт — звезда — двигается вниз на `SPEED` пикселей за кадр. Когда она уходит за нижний край ЭКРАНА, она возвращается наверх в новом случайном месте.

```basic id=c13-step2 endless wait=4 keys=LEFT vars="SY>=0"
CAT = SPAWN("cat",128,170)
STAR = SPAWN("star",RND(16,240),0)
SPEED = 2
DO
  IF KEY("LEFT") AND CAT.X > 16 THEN
    CAT.MOVE_BY -4,0
  END IF
  IF KEY("RIGHT") AND CAT.X < 240 THEN
    CAT.MOVE_BY 4,0
  END IF
  STAR.MOVE_BY 0,SPEED
  IF STAR.Y > 192 THEN
    STAR.MOVE RND(16,240),0
  END IF
  SY = STAR.Y
  FRAME
LOOP
```

Новые идеи: `RND(16,240)` держит звезду подальше от краёв, а наверх её возвращает `MOVE` (абсолютное положение), тогда как падение делает `MOVE_BY` (относительное).

## Шаг 3 · Поймай и посчитай

Теперь спросим `HIT(CAT,STAR)`. Когда они касаются, прибавляем очко, играем звук, ускоряемся и отправляем звезду наверх. Счёт пишется вверху ЭКРАНА и перерисовывается на каждом кадре.

```basic id=c13-step3 endless wait=4 keys=LEFT vars="SCORE>=0"
CAT = SPAWN("cat",128,170)
STAR = SPAWN("star",RND(16,240),0)
SPEED = 2
SCORE = 0
DO
  IF KEY("LEFT") AND CAT.X > 16 THEN
    CAT.MOVE_BY -4,0
  END IF
  IF KEY("RIGHT") AND CAT.X < 240 THEN
    CAT.MOVE_BY 4,0
  END IF
  STAR.MOVE_BY 0,SPEED
  IF HIT(CAT,STAR) THEN
    SCORE = SCORE + 1
    SPEED = 2 + SCORE / 4
    STAR.MOVE RND(16,240),0
    SFX "coin"
  END IF
  IF STAR.Y > 192 THEN
    STAR.MOVE RND(16,240),0
  END IF
  CLS 1
  INK 6
  TEXT 6,4,"СЧЁТ " + SCORE
  FRAME
LOOP
```

- `SPEED = 2 + SCORE / 4` делает игру сложнее: при 4 очках скорость 3, при 8 очках — 4.
- Используется `SFX`, а не `SOUND`, чтобы игра не делала пауз ради звука.
- `CLS 1` стирает рисунок и красит небо синим; спрайты остаются. Затем счёт рисуется заново с новым числом.

## Шаг 4 · Жизни, победа, поражение, перезапуск

Теперь целая игра. В ней используется автомат состояний из [главы 12](book:collisions-and-score): `STATE` равно 0 (подготовка), 1 (игра), 2 (победа) или 3 (поражение). Читай код сверху и сопоставляй каждую часть с предыдущим шагом.

```basic id=c13-star-catcher endless wait=30 keys=LEFT vars="LIVES>=0;SCORE>=0"
' STAR CATCHER - поймай десять звёзд; пропустишь три - конец
CAT = SPAWN("cat",128,170)
STAR = SPAWN("star",128,0)
STATE = 0
DO
  IF KEY("R") AND STATE > 1 THEN
    STATE = 0
  END IF
  IF STATE = 0 THEN
    SCORE = 0
    LIVES = 3
    SPEED = 2
    CAT.MOVE 128,170
    STAR.MOVE RND(16,240),0
    STAR.SHOW
    STATE = 1
  END IF
  IF STATE = 1 THEN
    IF KEY("LEFT") AND CAT.X > 16 THEN
      CAT.MOVE_BY -4,0
    END IF
    IF KEY("RIGHT") AND CAT.X < 240 THEN
      CAT.MOVE_BY 4,0
    END IF
    STAR.MOVE_BY 0,SPEED
    IF HIT(CAT,STAR) THEN
      SCORE = SCORE + 1
      SPEED = 2 + SCORE / 4
      STAR.MOVE RND(16,240),0
      SFX "coin"
    END IF
    IF STAR.Y > 192 THEN
      LIVES = LIVES - 1
      STAR.MOVE RND(16,240),0
      SFX "explosion"
    END IF
    IF SCORE = 10 THEN
      STATE = 2
      STAR.HIDE
    END IF
    IF LIVES = 0 THEN
      STATE = 3
      STAR.HIDE
    END IF
  END IF
  CLS 1
  BORDER 1
  INK 6
  TEXT 6,4,"СЧЁТ " + SCORE
  INK 2
  TEXT 186,4,"ЖИЗНИ " + LIVES
  IF STATE = 2 THEN
    INK 4
    TEXT 93,84,"ТЫ ПОБЕДИЛ!"
  END IF
  IF STATE = 3 THEN
    INK 2
    TEXT 86,84,"ИГРА ОКОНЧЕНА"
  END IF
  IF STATE > 1 THEN
    INK 7
    TEXT 38,106,"НАЖМИ R, ЧТОБЫ СЫГРАТЬ СНОВА"
  END IF
  FRAME
LOOP
```

### Разбор

1. **Подготовка спрайтов (до цикла).** Кот и звезда создаются один раз. При каждом перезапуске их только перемещают и показывают, а не создают заново.
2. **Блок `STATE = 0`.** Обнуляет счёт, жизни и скорость, возвращает оба спрайта на место и переходит в состояние 1. Это и код перезапуска, *и* код начала игры.
3. **Блок `STATE = 1`.** Один кадр игры: клавиши, падение звезды, поимка (очко, ускорение, новая звезда) и промах (потеря жизни). В конце проверяются два условия окончания. Оба `IF` прячут звезду, так что в законченной игре звезда не летает.
4. **Часть, которая рисует.** Выполняется всегда. Она стирает, показывает счёт и жизни и добавляет сообщение для состояния 2 или 3.
5. **`KEY("R")`.** В начале цикла. Работает только когда игра окончена.

## Сделай её своей

Три изменения, от лёгкого к более сложному:

1. **Легко:** поменяй число жизней, победный счёт (`SCORE = 10`) или формулу скорости.
2. **Средне:** добавь плохой спрайт (`slime`), который тоже падает. Поймать его — значит потерять жизнь.
3. **Сложнее:** покажи жизни маленькими спрайтами. Храни их в списке и прячь `HIDE` последний видимый при каждой потере жизни.

<details>
<summary>Подсказки и ответы</summary>

1. Меняются всего три числа: `LIVES = 3`, `SCORE = 10` и `2 + SCORE / 4`.
2. В начале создай `SLIME = SPAWN("slime",RND(16,240),0)`. Двигай его вниз, как звезду. `IF HIT(CAT,SLIME) THEN LIVES = LIVES - 1`, оформленный в несколько строк. Не забудь сбросить его при перезапуске.
3. `HEARTS = LIST()` и `FOR I = 1 TO 3` с `PUSH HEARTS,SPAWN("star",20 + I * 20,18)`. Когда `LIVES` уменьшается, возьми `ITEM(HEARTS,LIVES + 1)` и спрячь `HIDE`. В состоянии 0 покажи их все снова.

## Что ты узнал

- Законченная игра — это цикл с переменной `STATE`: сначала читаем клавиши, потом обновляем мир, в конце перерисовываем картинку.
- Игру можно строить контрольными точками, каждая из которых запускается.
- Каждую строку ты написал сам и можешь изменить любое число.
