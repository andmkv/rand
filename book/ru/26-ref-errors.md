# Справочник: сообщения об ошибках и ограничения

Когда что-то не так, машина останавливается, подсвечивает строку и показывает сообщение вида *Строка 7: …*. Сообщения написаны так, чтобы подсказать, что *попробовать*, а не ругать. Ниже — каждое сообщение, которое может прийти из программы, и программа, которая его вызывает. (Названия ошибок в первом столбце — внутренние коды; на экране ты их не увидишь, но они стабильны, и именно их проверяют тесты руководства.)

## Сообщения при чтении программы

Они появляются сразу после нажатия ЗАПУСК, до того как что-либо нарисовано, потому что машина сначала читает всю программу.

| Код | Сообщение | Обычная причина и исправление |
| --- | --- | --- |
| `token` | *Я нашёл здесь «…». Попробуй число, имя или слово в кавычках.* | Лишний символ, например `$`, `#`, `;`, `[`. |
| `quote` | *У этой строки не хватает закрывающей кавычки.* | Пропущена `"`. |
| `expected` | *Попробуй добавить здесь ….* | Пропущено слово или запятая, например `TO` в `FOR`, `THEN` в `IF` или перевод строки после `THEN`. Также `EXIT DO`, `EXIT FOR` или `EXIT SUB` без такого блока вокруг и два `SUB` с одним именем. |
| `block` | *Этому блоку нужно ….* | `IF`, `FOR`, `DO` или `SUB` без закрытия (`END IF`, `NEXT x`, `LOOP`, `END SUB`). |
| `limit` | *Вот это много магии! …* | Программа слишком длинная, слишком глубоко вложена или строка слишком длинная (см. также ниже). |

```basic id=e-token error=token
PRINT 5 $ 3
```

```basic id=e-quote error=quote
PRINT "oops
```

```basic id=e-expected error=expected
FOR X = 1 5
NEXT X
```

```basic id=e-block error=block
IF TRUE THEN
  PRINT 1
```

## Сообщения при выполнении программы

| Код | Сообщение | Обычная причина и исправление |
| --- | --- | --- |
| `unknown` | *Я не знаю заклинания …. Ты имел в виду …?* | Опечатка в названии команды, метода или свойства либо `CALL` несуществующего `SUB`. Подсказка — ближайшее настоящее имя. |
| `variable` | *Сначала присвой … значение.* | Переменная прочитана раньше, чем ей присвоили значение. |
| `number` | *Этому заклинанию нужно конечное число.* | Текст или истина/ложь там, где нужно число (`"a" * 2`, `INK "red"`). |
| `args` | *Для … нужно N ингредиентов.* | Неверное число аргументов: у `CIRCLE 1,2` их два, а нужно три. |
| `range` | *… вне диапазона этого заклинания.* | Значение вне допустимого для команды (`INK 9`, `WAIT 40`, `RND(5,1)`, `TEMPO 500`, отрицательный радиус). |
| `zero` | *Деление на ноль не помещается в этот мир.* | `x / 0` или `x MOD 0`. |
| `step` | *STEP не может быть равен нулю.* | `STEP 0` в `FOR`. |
| `functionStatement` | *… что-то возвращает. Сохрани результат под именем, например …* | Функция (`ROUND`, `ABS`, `RND`…) стоит одна на строке, а не внутри выражения. (Длинная форма вроде одинокого `SPAWN("cat",10,10)` сообщается раньше, как `expected`.) |
| `object` | *Здесь нужен живой спрайт. Сначала попробуй SPAWN.* | Метод вызван у уничтоженного спрайта или у того, что не спрайт. |
| `sprite` | *Попробуй один из этих спрайтов: …* | `SPAWN` с неизвестным именем. В сообщении перечислены настоящие. |
| `sound` | *Этого звука нет в ИНВЕНТАРЕ. …* | `SOUND` / `SFX` / псевдоним инструмента, которого не существует. |
| `list` | *Здесь нужен плоский LIST из чисел, слов или спрайтов.* | Не-список там, где нужен список, или список внутри списка. |
| `index` | *Такого места в списке нет. …* | `ITEM(список,n)` или `SET список,n,значение` с `n` меньше 1 или больше `COUNT(список)`. |
| `key` | *Попробуй LEFT, RIGHT, UP, DOWN, SPACE, ENTER или клавишу с буквой или цифрой.* | `KEY("ESC")` или другое неизвестное имя клавиши. |
| `input` | *Введи число для ….* | Набрана буква там, где `INPUT` ждал число. |
| `limit` | *Вот это много магии! Попробуй цикл поменьше или меньше фигур и звуков.* | Достигнуто ограничение (см. таблицу ниже). |
| `stopped` | *Остановлено.* | Ты нажал СТОП. Это не ошибка. |

```basic id=e-unknown error=unknown
CIRCL 128,96,20
```

```basic id=e-variable error=variable
PRINT SCORE
```

```basic id=e-number error=number
PRINT "a" * 2
```

```basic id=e-args error=args
CIRCLE 1,2
```

```basic id=e-range error=range
INK 9
```

```basic id=e-zero error=zero
PRINT 1 / 0
```

```basic id=e-step error=step
FOR I = 1 TO 5 STEP 0
NEXT I
```

```basic id=e-function error=functionStatement
ROUND(2.5)
```

```basic id=e-object error=object
A = SPAWN("cat",1,1)
A.DESTROY
A.MOVE 5,5
```

```basic id=e-sprite error=sprite
A = SPAWN("dragon",1,1)
```

```basic id=e-sound error=sound
SFX "missing"
```

```basic id=e-list error=list
PRINT COUNT(5)
```

```basic id=e-index error=index
PRINT ITEM(LIST(1,2),3)
```

```basic id=e-key error=key
PRINT KEY("ESCAPE")
```

```basic id=e-input error=input input="abc"
N = 5
INPUT "Number?", N
```

Для `unknown` машина знает названия команд, методов и свойств спрайтов, перечисленных в этом справочнике, а подсказка — ближайшее по написанию.

## Сообщения о файлах и ресурсах

Они вызваны не твоей программой, а открытием или загрузкой чего-либо.

| Код | Сообщение | Что произошло |
| --- | --- | --- |
| `importInvalid` | *Этот файл не проект Randomize USR. Текущий проект не изменён.* | Файл повреждён, это не файл `.randusr`, или его содержимое не проходит проверку. |
| `importVersion` | *Этот проект создан в более новой версии Randomize USR (версия N). Обнови приложение …* | Формат файла новее, чем понимает это приложение. |
| `importLarge` | *Файл слишком большой. Попробуй .randusr меньше 1 МБ.* | Файл больше 1 МБ. |
| `assetUnavailable` | *Не удалось загрузить спрайт. Проверь соединение и попробуй ещё раз.* | Картинка встроенного или сохранённого спрайта не загрузилась. |
| `audio` | *Звук не запустился. Нажми «Слушать» или ЗАПУСК ещё раз.* | Браузер отказался запускать звук. |
| `internal` | *Заклинание не смогло закончиться. Попробуй сбросить мир.* | Произошло что-то неожиданное; нажми СБРОС. |

## Ограничения в одной таблице

| Ограничение | Значение | При превышении |
| --- | --- | --- |
| Длина программы | 100 000 символов | `limit` |
| Длина строки (текста) | 2000 символов | `limit` |
| Длина имени | 64 символа | `limit` |
| Вложенность блоков | 40 уровней | `limit` |
| `SUB`, вызывающие друг друга | 32 уровня | `limit` |
| Глубина выражения | 80 | `limit` |
| Операторов за запуск (без `DO`) | 30 000 | `limit` |
| Проходов циклов за запуск (без `DO`) | 10 000 | `limit` |
| Один цикл `FOR` | 10 000 проходов | `limit` |
| Время работы (без `DO`) | 120 секунд | `limit` |
| Координаты | ±10 000 | `range` |
| `WAIT` | от 0 до 30 с | `range` |
| `TEXT` | 120 символов за вызов | лишние символы не рисуются |
| `PRINT` | 1000 символов в строке | лишние символы не показываются |
| `SAY` | 40 символов | лишние символы отрезаются |
| Живых спрайтов | 128 | `limit` |
| Созданных спрайтов (без `DO`) | 512 | `limit` |
| Размер спрайта | 1–256 × 1–192 | `range` |
| Длина списка | 128 элементов | `limit` |
| Нот в `PLAY` | 64 за вызов | `limit` |
| `TEMPO` | 30–300 | `range` |
| Запусков звука за запуск (без `DO`) | 256 | `limit` |
| Запусков звука в секунду | 32 | лишние молча отбрасываются |
| Одновременных звуков | 8 | лишние молча отбрасываются |
| Файл `.randusr` | 1 МБ | `importLarge` |

```basic id=e-limit error=limit
A = LIST()
FOR I = 1 TO 129
  PUSH A,I
NEXT I
```
