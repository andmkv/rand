# Читаем настоящие игры

**Цель:** учиться на «взрослом» коде. В ящике ПРИМЕРЫ под заголовком **ИГРЫ** лежат три целые игры. Они написаны на том же языке, который ты изучаешь, и ничего не спрятано. Эта глава показывает интересные места.

| Игра | Клавиши | Чем интересна |
| --- | --- | --- |
| **АТАКА ПРИШЕЛЬЦЕВ** (ALIEN ATTACK) | ← → движение, ПРОБЕЛ выстрел, R заново | Сетка врагов двигается как блок; одна пуля, которую используют снова и снова. |
| **РАЗБЕЙ КИРПИЧИ** (BRICK BREAKER) | ← → двигают ракетку, R заново | Отскакивающий мяч с простой физикой; стена из кирпичей в списке. |
| **ПИКСЕЛЬНЫЙ ПОХОД** (PIXEL QUEST) | ← → ходьба, ПРОБЕЛ прыжок, R заново | Гравитация, приземление на платформы, звёзды для сбора и дверь. |

Открой любую из ПРИМЕРОВ, нажми ЗАПУСК, поиграй, а потом читай код рядом с этой главой. Куски ниже процитированы из игр слово в слово, а проверка руководства следит, чтобы они по-прежнему совпадали.

> [!NOTE]
> Игры идут в ящике ПРИМЕРЫ такими, какие они есть. Изменение копии никогда не меняет оригинал, и оригинал всегда можно загрузить из ящика заново. Надписи в играх остаются английскими, как в оригинале.

## Общая структура

У всех трёх игр общий скелет из прошлых глав: один раз подготовить спрайты, затем цикл `DO … LOOP`, который читает `STATE`, и часть, рисующая интерфейс заново через `CLS 0`. Обрати внимание: перезапуск — это просто снова `STATE = 0`:

```basic id=c14-alien-state fragment quote=alien-attack
STATE = 0
DO
  IF KEY("R") AND STATE > 1 THEN
    STATE = 0
  END IF
  IF STATE = 0 THEN
    SCORE = 0
```

## АТАКА ПРИШЕЛЬЦЕВ

### Одна пуля, много выстрелов

В игре один спрайт-пуля, который прячется, когда не нужен. `SHOT.VISIBLE` — флаг «летит ли она?». Сравни с выстрелом из [главы 11](book:keyboard):

```basic id=c14-alien-shot fragment quote=alien-attack
    IF KEY("LEFT") AND SHIP.X > 10 THEN
      SHIP.MOVE_BY -3,0
    END IF
    IF KEY("RIGHT") AND SHIP.X < 246 THEN
      SHIP.MOVE_BY 3,0
    END IF
    IF KEY("SPACE") AND NOT SHOT.VISIBLE THEN
      SHOT.MOVE SHIP.X,164
      SHOT.SHOW
      SFX "laser"
    END IF
    IF SHOT.VISIBLE THEN
      SHOT.MOVE_BY 0,-4
      IF SHOT.Y < 20 THEN
        SHOT.HIDE
      END IF
    END IF
```

### Сетка из списка

Десять пришельцев живут в списке. На каждом кадре каждый пришелец ставится на место по двум общим числам, `WAVE_X` и `WAVE_Y`, плюс его собственный столбец и ряд. Чтобы подвинуть весь строй, меняют только эти два числа:

```basic id=c14-alien-grid fragment quote=alien-attack
    FOR N = 1 TO COUNT(ALIENS)
      ALIEN = ITEM(ALIENS,N)
      COLUMN = N-1
      ROW = 0
      IF N > 5 THEN
        COLUMN = N-6
        ROW = 1
      END IF
      ALIEN.MOVE WAVE_X+COLUMN*38,WAVE_Y+ROW*26
      IF HIT(SHOT,ALIEN) THEN
        ALIEN.HIDE
        SHOT.HIDE
        SCORE = SCORE+10
        SFX "coin"
      END IF
```

Попадание прячет пришельца, а не уничтожает его, поэтому список остаётся полным, и при перезапуске всех можно показать снова.

### Интерфейс

Последняя часть цикла на каждом кадре заново рисует название и счёт:

```basic id=c14-alien-hud fragment quote=alien-attack
  CLS 0
  BORDER 1
  INK 5
  TEXT 6,5,"ALIEN ATTACK"
  INK 7
  TEXT 170,5,"SCORE "+SCORE
```

**Попробуй:** подсказка самой игры — поменять `SPEED = 0.24` на `0.4`, и пришельцы станут быстрее.

## РАЗБЕЙ КИРПИЧИ

### Стена в списке

Вложенные циклы из главы 5 строят стену; переменная `KIND` выбирает спрайт для каждого ряда, а `SIZE` делает каждый кирпич 30 × 10 пикселей:

```basic id=c14-brick-wall fragment quote=brick-breaker
BRICKS = LIST()
FOR ROW = 1 TO 3
  FOR COLUMN = 1 TO 6
    KIND = "brick_red"
    IF ROW = 2 THEN
      KIND = "brick_cyan"
    END IF
    IF ROW = 3 THEN
      KIND = "brick_yellow"
    END IF
    BRICK = SPAWN(KIND,COLUMN*36+2,26+ROW*14)
    BRICK.SIZE 30,10
    PUSH BRICKS,BRICK
  NEXT COLUMN
NEXT ROW
```

### Физика мяча

У мяча есть своя позиция (`X`, `Y`) и скорость (`VX`, `VY`) в обычных переменных, а спрайт просто переставляется туда. Стены меняют знак скорости. Ракетка меняет `VY` и ещё *прицеливает* мяч: чем дальше от центра ракетки он приземлился, тем сильнее летит вбок (`VX = (X-PADDLE.X)/10`).

```basic id=c14-brick-ball fragment quote=brick-breaker
    OLD_Y = Y
    X = X+VX
    Y = Y+VY
    IF X < 4 OR X > 252 THEN
      VX = -VX
      X = X+VX
    END IF
    IF Y < 22 THEN
      VY = ABS(VY)
    END IF
    BALL.MOVE X,Y
    IF HIT(BALL,PADDLE) AND VY > 0 THEN
      Y = PADDLE.Y-PADDLE.HEIGHT/2-BALL.HEIGHT/2
      VY = -ABS(VY)
      VX = (X-PADDLE.X)/10
      IF ABS(VX) < 0.8 THEN
        VX = 0.8
      END IF
      SFX "jump"
    END IF
```

Посмотри на `VY = ABS(VY)` у потолка: он гонит мяч вниз, не зная, куда тот летел раньше. А `AND VY > 0` заставляет ракетку игнорировать мяч, который уже летит вверх, чтобы мяч не застревал внутри ракетки.

**Попробуй:** сделай ракетку удобнее: `PADDLE.SIZE 60,8` в начале программы.

## ПИКСЕЛЬНЫЙ ПОХОД

### Прыжок, гравитация и приземление

Это самый сложный кусок. У героя есть вертикальная скорость `VY`. Гравитация прибавляет 0,22 на каждом кадре. Прыжок задаёт `VY` отрицательным числом (вверх). Приземление означает: на прошлом кадре герой был над верхом платформы, сейчас он на нём или ниже, а по горизонтали находится над платформой.

```basic id=c14-quest-jump fragment quote=pixel-quest
    IF JUMP_HELD AND NOT WAS_JUMP AND GROUNDED THEN
      VY = JUMP
      SFX "jump"
    END IF
    OLD_BOTTOM = Y+HERO.HEIGHT/2
    VY = VY+0.22
    Y = Y+VY
    GROUNDED = FALSE
    FOR N = 1 TO COUNT(PLATFORMS)
      LEDGE = ITEM(PLATFORMS,N)
      TOP = LEDGE.Y-LEDGE.HEIGHT/2
      IF VY >= 0 AND OLD_BOTTOM <= TOP AND Y+HERO.HEIGHT/2 >= TOP THEN
        IF ABS(X-LEDGE.X) < (LEDGE.WIDTH+HERO.WIDTH)/2 THEN
          Y = TOP-HERO.HEIGHT/2
          VY = 0
          GROUNDED = TRUE
        END IF
      END IF
    NEXT N
```

Три идеи, которые стоит забрать с собой:

1. **Запоминай прежнюю позицию** (`OLD_BOTTOM`). Сравнение «до» и «после» не даёт герою провалиться сквозь тонкие платформы на большой скорости.
2. **Один прыжок за нажатие.** `JUMP_HELD AND NOT WAS_JUMP` — это приём «была ли зажата?» из [главы 11](book:keyboard), а `GROUNDED` не даёт прыгать в воздухе.
3. **Цикл по платформам.** Та же проверка работает для любого числа платформ, потому что они лежат в списке.

**Попробуй:** поменяй `JUMP = -4.8` на `-5.4`, чтобы прыгать выше.

## Как учиться по чужому коду

Читая чужую программу, не начинай с верха и не пытайся понять каждую строку. Лучше так:

1. **Запусти** и поиграй. Назови всё, что видишь.
2. **Найди переменную состояния** и главный цикл `DO`.
3. **Поменяй одно число** и угадай, что произойдёт, прежде чем запускать.
4. **Удали один блок** и посмотри, что сломается.

## Что ты узнал

- Настоящие игры используют те же немногие идеи: состояния, списки, прежние позиции и клавиши на одно нажатие.
- Игры из ящика ПРИМЕРЫ можно читать, запускать и менять.
