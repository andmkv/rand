# Справочник: рисование

## ЭКРАН и слой рисунка

- ЭКРАН — **256 × 192** пикселя, рисуется с масштабированием по ближайшему соседу, поэтому пиксели остаются квадратными и чёткими при любом размере.
- Начало `0,0` — **левый верхний** пиксель. `x` растёт вправо (от 0 до 255), `y` растёт вниз (от 0 до 191).
- Координаты могут быть дробными; они **округляются** до ближайшего пикселя. Всё, что за пределами ЭКРАНА, обрезается (не рисуется). Координата больше ±10 000 — ошибка (`range`).
- Команды рисования красят **слой рисунка**. Более поздняя краска закрывает более раннюю. **Спрайты** рисуются над этим слоем, затем идут облачка с речью, затем искры взрыва. `CLS` очищает только слой рисунка.
- Машина хранит запись о последних **512** фигурах, которой пользуется `EXPLODE`, чтобы решить, что стирать. Пиксели, которые уже нарисованы, остаются на ЭКРАНЕ в любом случае, а `EXPLODE` стирает каждый пиксель в радиусе взрыва.
- Каждой команде рисования даются целые или дробные числа; строки в качестве координат не допускаются (ошибка `number`).

### Палитра

Шестнадцать цветов — классический набор Spectrum. `INK`, `PAPER` и `BORDER` принимают номер цвета `0`–`7`; `BRIGHT` выбирает оттенок.

| n | Цвет | `BRIGHT 0` | `BRIGHT 1` |
| --- | --- | --- | --- |
| 0 | чёрный | `#000000` | `#000000` |
| 1 | синий | `#0000BF` | `#0000FF` |
| 2 | красный | `#BF0000` | `#FF0000` |
| 3 | пурпурный | `#BF00BF` | `#FF00FF` |
| 4 | зелёный | `#00BF00` | `#00FF00` |
| 5 | голубой | `#00BFBF` | `#00FFFF` |
| 6 | жёлтый | `#BFBF00` | `#FFFF00` |
| 7 | белый | `#BFBFBF` | `#FFFFFF` |

Каждая фигура берёт свой цвет в момент рисования, по действующим тогда `INK` и `BRIGHT`. Пустой фон закрашивается текущими `PAPER` и `BRIGHT`. В начале каждого ЗАПУСКА машина возвращается к `INK 7`, `PAPER 0`, `BORDER 1`, `BRIGHT 1`.

### Когда рисуется

Если в программе нет `FRAME`, машина даёт браузеру нарисовать картинку после каждых 8 команд рисования (или раньше при очень больших фигурах), поэтому длинный рисунок видно, как он строится. Если в программе есть `FRAME`, рисование не нарезается, а `FRAME` отмечает конец картинки. См. [`FRAME`](book:ref-time-input#cmd-frame).

## Команды цвета и экрана

### `CLS` {#cmd-cls}

**Синтаксис:** `CLS [цвет]`

Очищает слой рисунка (всё, что нарисовано другими командами рисования). Если указан цвет `0`–`7`, ещё и ставит `PAPER` этого цвета. Спрайты не трогает. Не блокирует.

```basic id=r-cls px="10,10=13;100,100=13"
INK 2
FILLBOX 90,90,20,20
CLS 5
```

### `INK` {#cmd-ink}

**Синтаксис:** `INK цвет` · цвет — целое число `0`–`7`.

Выбирает цвет всего, что рисуется после неё, в том числе `TEXT`. Другие значения дают ошибку `range`.

```basic id=r-ink px="50,50=9;60,50=12"
INK 1
PLOT 50,50
INK 4
PLOT 60,50
```

### `PAPER` {#cmd-paper}

**Синтаксис:** `PAPER цвет` · `0`–`7`.

Задаёт цвет фона позади рисунка. Меняет сразу весь пустой фон.

```basic id=r-paper px="5,5=10;100,100=15"
PAPER 2
INK 7
PLOT 100,100
```

### `BORDER` {#cmd-border}

**Синтаксис:** `BORDER цвет` · `0`–`7`.

Задаёт цвет рамки вокруг ЭКРАНА. Рамка находится вне картинки 256 × 192.

```basic id=r-border events=BORDER
BORDER 4
```

### `BRIGHT` {#cmd-bright}

**Синтаксис:** `BRIGHT 0` или `BRIGHT 1`

Выбирает оттенок (см. палитру). Допустимы только `0` и `1`.

```basic id=r-bright px="10,10=2;20,10=10"
BRIGHT 0
INK 2
PLOT 10,10
BRIGHT 1
PLOT 20,10
```

## Фигуры

### `PLOT` {#cmd-plot}

**Синтаксис:** `PLOT x,y`

Зажигает один пиксель текущим цветом.

```basic id=r-plot px="128,96=15"
PLOT 128,96
```

### `LINE` {#cmd-line}

**Синтаксис:** `LINE x1,y1,x2,y2`

Рисует прямую линию толщиной в один пиксель между двумя точками, включая оба конца. Линии бывают любого направления.

```basic id=r-line px="10,10=15;100,50=15;60,30=15"
LINE 10,10,100,50
PLOT 60,30
```

### `BOX` {#cmd-box}

**Синтаксис:** `BOX x,y,ширина,высота`

Контур прямоугольника толщиной в один пиксель. `x,y` — левый верхний угол; прямоугольник занимает `ширина` × `высота` пикселей, так что правый край находится в `x + ширина - 1`. Ширина и высота не могут быть отрицательными (иначе `range`).

```basic id=r-box px="20,20=15;49,39=15;30,30=8"
BOX 20,20,30,20
```

### `FILLBOX` {#cmd-fillbox}

**Синтаксис:** `FILLBOX x,y,ширина,высота`

Закрашенный прямоугольник с теми же правилами для угла, что у `BOX`.

```basic id=r-fillbox px="20,20=12;49,39=12;50,40=8"
INK 4
FILLBOX 20,20,30,20
```

### `CIRCLE` {#cmd-circle}

**Синтаксис:** `CIRCLE x,y,радиус`

Контур круга толщиной примерно в один пиксель с **центром** в `x,y`. Радиус не может быть отрицательным.

```basic id=r-circle px="158,96=15;128,66=15;128,96=8"
CIRCLE 128,96,30
```

### `FILLCIRCLE` {#cmd-fillcircle}

**Синтаксис:** `FILLCIRCLE x,y,радиус`

Закрашенный круг с центром в `x,y`. Большие круги обходятся дороже по времени рисования, чем маленькие фигуры, поэтому после такого круга машина делает паузу на отрисовку.

```basic id=r-fillcircle px="128,96=9;158,96=9;160,96=8"
INK 1
FILLCIRCLE 128,96,30
```

### `TEXT` {#cmd-text}

**Синтаксис:** `TEXT x,y,значение`

Пишет текст пиксельным шрифтом. `x,y` — левый верхний угол клетки первой буквы. Третье значение превращается в текст, если оно ещё не текст (так что `TEXT 10,10,SCORE` работает), и рисуется не больше **120 символов**.

Ширина букв переменная: большинство латинских букв — 4–10 пикселей; широкие символы (например, японские) — 16. Клетка буквы высотой 18 пикселей; заглавные буквы занимают в ней строки 3–12. Шрифт покрывает латиницу с диакритикой, кириллицу, греческий и многие японские символы; недоступный символ показывается как маленький перечёркнутый квадратик. Текст не переносится: всё, что правее края, обрезается.

```basic id=r-text events=TEXT
INK 6
TEXT 20,20,"Hello, мир!"
TEXT 20,50,12345
```
