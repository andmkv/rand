# Списки: много вещей сразу

**Цель:** хранить целую толпу значений (цвета, очки, спрайты) под одним именем и обрабатывать их все в цикле.

## Проблема

Шесть привидений можно сделать шестью переменными: `G1`, `G2`, `G3`… А если их шестьдесят? И как цикл выберет «привидение номер I»? Эту задачу решает **список**: одна переменная, в которой по порядку лежит много значений.

## Создаём и читаем список

```basic id=c09-basics output="3|2|4|5"
COLORS = LIST(2,4,6)
PRINT COUNT(COLORS)
PRINT ITEM(COLORS,1)
PUSH COLORS,5
PRINT COUNT(COLORS)
PRINT ITEM(COLORS,4)
```

- `LIST(2,4,6)` создаёт список из трёх значений. `LIST()` создаёт пустой.
- `COUNT(список)` возвращает количество элементов.
- `ITEM(список,n)` возвращает элемент на позиции *n*.
- `PUSH список,значение` добавляет значение в конец. Это команда, а не функция, поэтому скобок нет.

> [!WARNING]
> Позиции считаются с **1**, а не с 0. Первый элемент — `ITEM(список,1)`, последний — `ITEM(список,COUNT(список))`. Если спросить элемент 0 или на единицу дальше конца, будет ошибка *Такого места в списке нет.*

В списке могут лежать числа, строки, `TRUE`/`FALSE` и спрайты, причём в одном списке можно смешивать. **Нельзя класть список в список**, и в списке может быть не больше **128 элементов**. Команды для удаления элемента нет; чтобы начать заново, создай новый список. А вот заменить элемент, который уже лежит в списке, *можно* — об этом следующий раздел.

## Меняем элемент: `SET`

`SET список,n,значение` кладёт новое значение на место номер *n*. Старое значение пропадает, а длина списка остаётся прежней. С `SET` список работает как ряд пронумерованных коробочек, которые можно и читать, и записывать:

```basic id=c09-set output="0|5|3"
SCORES = LIST(0,0,0)
PRINT ITEM(SCORES,1)
SET SCORES,1,5
PRINT ITEM(SCORES,1)
PRINT COUNT(SCORES)
```

`SET` никогда не делает список длиннее: если попросить место, которого нет, будет сообщение «Такого места в списке нет.» Чтобы список вырос, используй `PUSH`.

Вот настоящее применение: брось кубик 60 раз и веди подсчёт для каждой грани. Коробочка *n* списка `TALLY` считает, сколько раз выпала грань *n*. Строка с `SET` читает старый счёт через `ITEM`, прибавляет единицу и записывает обратно:

```basic id=c09-tally output="6|60"
TALLY = LIST(0,0,0,0,0,0)
FOR ROLL = 1 TO 60
  FACE = RND(1,6)
  SET TALLY,FACE,ITEM(TALLY,FACE) + 1
NEXT ROLL
TOTAL = 0
FOR F = 1 TO COUNT(TALLY)
  TOTAL = TOTAL + ITEM(TALLY,F)
NEXT F
PRINT COUNT(TALLY)
PRINT TOTAL
```

Шесть коробочек, и вместе в них все 60 бросков. Попробуй нарисовать столбик для каждой коробочки через `FILLBOX` и посмотри, какая грань победила.

## Обходим все элементы

Соедини `COUNT` с циклом `FOR`, и ты обработаешь любой список любой длины:

```basic id=c09-rainbow px="30,40=10;30,60=14;30,84=12"
COLORS = LIST(2,6,4,5,1,3)
FOR I = 1 TO COUNT(COLORS)
  INK ITEM(COLORS,I)
  FILLBOX 20,10 + I * 24,216,20
NEXT I
```

Добавь в список седьмой цвет, и в картинке появится седьмая полоса — больше ничего менять не надо.

## Списки спрайтов

Настоящая сила — список спрайтов. Создавай их в цикле и клади каждый через `PUSH`:

```basic id=c09-ghosts sprites=5 output="1|2|3|4|5"
GHOSTS = LIST()
FOR I = 1 TO 5
  G = SPAWN("ghost",30 + I * 40,100)
  PUSH GHOSTS,G
NEXT I
FOR I = 1 TO COUNT(GHOSTS)
  G = ITEM(GHOSTS,I)
  G.MOVE_BY 0,-20
  G.SAY I
  PRINT I
NEXT I
```

`ITEM(GHOSTS,I)` возвращает сам спрайт, так что можно вызывать его методы и читать свойства, как раньше. В списке лежат не *копии*: он хранит ссылки на тех же привидений, которые стоят на ЭКРАНЕ.

То же и со списками: `B = A` не копирует список, а даёт одному и тому же списку второе имя.

## Волна привидений

Соединим список, цикл и `SIN`:

```basic id=c09-wave endless wait=4 vars="T>0"
GHOSTS = LIST()
FOR I = 1 TO 8
  PUSH GHOSTS,SPAWN("ghost",20 + I * 28,100)
NEXT I
T = 0
DO
  T = T + 0.1
  FOR I = 1 TO COUNT(GHOSTS)
    G = ITEM(GHOSTS,I)
    G.MOVE 20 + I * 28,100 + SIN(T + I * 0.7) * 30
  NEXT I
  FRAME
LOOP
```

Обрати внимание: `SPAWN(...)` можно писать прямо внутри `PUSH`. Результат функции — такое же значение, как и любое другое.

## Списки слов, списки позиций

Списки хороши и для таблиц с данными. Список сообщений, из которого выбирается случайное:

```basic id=c09-words vars="N>=1;N<=4"
MESSAGES = LIST("Привет!","Будь смелым","Попробуй ещё","Отлично")
N = RND(1,COUNT(MESSAGES))
PRINT ITEM(MESSAGES,N)
```

Используй `RND(1,COUNT(список))`, когда нужен случайный элемент.

## Попробуй

1. Добавь `"оранжевый"` в список из 5 названий цветов и напечатай все по порядку циклом.
2. Сделай ряд из 10 звёзд и увеличь ту, что в середине.
3. Создай 20 слизней в списке, а затем `DESTROY` только тех, чья позиция в списке чётная. (Подсказка: приём «раздели и округли» из главы 6.)

<details>
<summary>Подсказки и ответы</summary>

1. `NAMES = LIST("красный","зелёный","синий")`, `PUSH NAMES,"оранжевый"`, затем `FOR I = 1 TO COUNT(NAMES)` и `PRINT ITEM(NAMES,I)`.
2. Середина десяти — позиции 5 и 6. `ITEM(STARS,5).SIZE` не сработает (методу нужна переменная), так что сначала сохрани: `S = ITEM(STARS,5)`, а потом `S.SIZE 32,32`.
3. `IF I / 2 = ROUND(I / 2) THEN`, затем `S = ITEM(SLIMES,I)` и `S.DESTROY`. Уничтоженные спрайты остаются в списке; если спросить у такого `ALIVE`, будет `false`.

</details>

## Что ты узнал

- `LIST(...)`, `COUNT`, `ITEM` и `PUSH` создают и используют списки. Счёт идёт с 1.
- В списках до 128 плоских значений, в том числе спрайтов, и они общие, а не копируются.
- `FOR I = 1 TO COUNT(список)` обходит каждый элемент.
