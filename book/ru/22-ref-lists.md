# Справочник: списки

**Список** — упорядоченный ряд значений. Списки — такие же значения, как любые другие: храни их в переменных, передавай, сравнивай.

## Правила

- Элементы нумеруются с **1**.
- В списке до **128** элементов. 129-й элемент — ошибка `limit`.
- Элементами могут быть числа, строки, логические значения и спрайты, вперемешку. Список не может содержать другой список (ошибка `list`).
- Списки **общие, а не копируются**: после `B = A` оба имени — один и тот же список, и `PUSH B,1` меняет то, что видит `A`.
- Команды удаления или вставки элементов нет. Создай новый список.
- Список там, где нужно число, — ошибка `number`; не-список в `ITEM`, `COUNT` или `PUSH` — ошибка `list`.

## Функции и команды

### `LIST` {#fn-list}

**Синтаксис:** `LIST(значение, значение, …)` → список. `LIST()` — пустой.

Строит список из своих аргументов, которые сначала вычисляются. Не больше 128 аргументов; ни один не может быть списком.

### `ITEM` {#fn-item}

**Синтаксис:** `ITEM(список, индекс)` → значение на этой позиции.

`индекс` должен быть целым числом от 1 до `COUNT(список)`; иначе ошибка `index` («Такого места в списке нет»).

### `COUNT` {#fn-count}

**Синтаксис:** `COUNT(список)` → количество элементов.

### `PUSH` {#cmd-push}

**Синтаксис:** `PUSH список, значение` · команда, а не функция.

Добавляет `значение` в конец списка. Значением может быть любое не-список, в том числе только что созданный спрайт: `PUSH ENEMIES,SPAWN("slime",20,20)`.

```basic id=r-list output="3|20|30|4|99|b"
NUMBERS = LIST(10,20,30)
PRINT COUNT(NUMBERS)
PRINT ITEM(NUMBERS,2)
ALIAS = NUMBERS
PUSH ALIAS,99
PRINT ITEM(NUMBERS,3)
PRINT COUNT(NUMBERS)
PRINT ITEM(NUMBERS,4)
WORDS = LIST("a","b")
PRINT ITEM(WORDS,2)
```

Программа печатает количество (3), второй элемент (20), затем добавляет 99 через псевдоним `ALIAS` и печатает третий элемент (30), новое количество (4), четвёртый элемент (99) и, наконец, слово из другого списка.
