# Справочник: время, клавиши и ввод текста

## Как машина выполняет программу

Твоя программа выполняется в браузере по одному оператору за раз, но она **кооперативная**: регулярно возвращает управление, чтобы страница могла рисовать, играть звук и реагировать на СТОП. Поэтому тесный цикл никогда не подвешивает страницу, а СТОП всегда работает. Основные места, где идёт время, — команды ожидания (`WAIT`, `FRAME`, `INPUT`, `SOUND`, `BEEP`, `NOTE`, `REST`, `PLAY`, `EXPLODE`).

Программа, в которой **нет** `DO … LOOP`, ещё и ограничена: не больше 30 000 операторов, 10 000 проходов циклов и двух минут работы, после чего она останавливается с ошибкой `limit`. Программа с `DO` считается долго работающей, и таких ограничений у неё нет, но её всё равно можно остановить, а число спрайтов, списков и звуков всё равно ограничено.

## Время

### `WAIT` {#cmd-wait}

**Синтаксис:** `WAIT секунды` · от 0 до 30; дробные допустимы. **Блокирует.**

Приостанавливает программу на столько секунд. Вне 0–30 — ошибка `range` («duration»). СТОП прерывает ожидание сразу.

```basic id=r-wait output="one|two"
PRINT "one"
WAIT 0.5
PRINT "two"
```

### `FRAME` {#cmd-frame}

**Синтаксис:** `FRAME` · без аргументов. **Блокирует** примерно на 1/60 секунды.

Ждёт следующего обновления экрана. Используй один раз на проход игрового цикла: тогда цикл идёт примерно 60 раз в секунду. Программа, в которой где-либо есть `FRAME`, считается *кадровой*: команды рисования больше не нарезаются, между двумя `FRAME` выполняется до 1000 операторов, и всё нарисованное появляется сразу.

```basic id=r-frame vars="N=30"
N = 0
FOR T = 1 TO 30
  N = N + 1
  FRAME
NEXT T
```

## Вывод текста

### `PRINT` {#cmd-print}

**Синтаксис:** `PRINT значение` · ровно одно значение.

Пишет одну строку в текстовую область под ЭКРАНОМ (до 1000 символов). Числа, текст и логические значения превращаются в текст; чтобы вывести несколько вещей, используй `+`. Текстовая область не входит в ЭКРАН: чтобы писать на ЭКРАНЕ, используй [`TEXT`](book:ref-drawing#cmd-text).

```basic id=r-print output="3 apples|true"
PRINT 3 + " apples"
PRINT 2 < 3
```

## Ввод текста

### `INPUT` {#cmd-input}

**Синтаксис:** `INPUT вопрос, имя` · **Блокирует**, пока игрок не ответит.

Показывает вопрос (строку или любое значение, превращённое в текст) и ждёт ответа, набранного в поле под ЭКРАНОМ. Ответ попадает в переменную `имя`.

- Если в `имя` **уже лежит число**, ответ должен быть числом; он сохраняется числом. Всё остальное даёт ошибку `input` («Введи число для NAME»).
- Иначе ответ сохраняется как **текст**.

СТОП отменяет ожидающий `INPUT`.

```basic id=r-input input="Mia|7" output="Mia is 8"
AGE = 0
INPUT "Name?", NAME
INPUT "Age?", AGE
PRINT NAME + " is " + (AGE + 1)
```

## Клавиатура

### `KEY` {#fn-key}

**Синтаксис:** `KEY(имя)` → `TRUE` или `FALSE` · ровно один аргумент.

Отвечает, **зажата ли клавиша прямо сейчас**. `имя` — строка, регистр не важен: `"LEFT"`, `"RIGHT"`, `"UP"`, `"DOWN"`, `"SPACE"`, `"ENTER"`, одна буква `"A"`–`"Z"` или одна цифра `"0"`–`"9"`. Всё остальное — ошибка `key`.

- Клавиши доходят до программы, только пока **фокус на ЭКРАНЕ**. Первый вызов `KEY` за запуск переводит фокус туда; щелчок по КОДУ отдаёт его редактору, а щелчок по ЭКРАНУ возвращает. Когда окно или вкладка браузера теряет фокус, все клавиши отпускаются.
- Буквы и цифры читаются по их **физическому положению** на клавиатуре, так что одна и та же программа работает с другими раскладками.
- Нажатия вместе с `Ctrl`, `⌘` или `Alt` игнорируются.
- `KEY` — функция: используй её в условии или присваивай: `HELD = KEY("SPACE")`.

```basic id=r-key endless wait=2 keys=SPACE vars="PRESSED=1"
PRESSED = 0
DO
  IF KEY("SPACE") THEN
    PRESSED = 1
  END IF
  FRAME
LOOP
```
