# Справочник: спрайты

**Спрайт** — движущийся объект-картинка. Его даёт [`SPAWN`](#fn-spawn), ты хранишь его в переменной, отдаёшь приказы **методами** (`ИМЯ.МЕТОД аргументы`) и спрашиваешь о нём **свойствами** (`ИМЯ.СВОЙСТВО`).

## Факты, верные для каждого спрайта

- Его **позиция** `x,y` — это его **центр**. Спрайты начинают размером **16 × 16** пикселей и рисуются над слоем рисунка в том порядке, в каком были созданы (более новый спрайт закрывает более старый).
- Картинки встроенных спрайтов — это графика 8 × 8, показанная как 16 × 16. [`SIZE`](#method-size) растягивает их. Собственные спрайты (названия начинаются с `@`) рисуются в собственном размере в пикселях, пока не вызван `SIZE`, но их свойства `WIDTH` и `HEIGHT`, а также `HIT`, пока не вызван `SIZE`, всё равно используют 16.
- Спрайт **жив** с момента `SPAWN` до `DESTROY` или до `EXPLODE`, который его задел. Приказ уничтоженному спрайту или чтение любого свойства, кроме `ALIVE`, даёт ошибку `object` («Здесь нужен живой спрайт»).
- Метод, вызванный у чего-то, что не спрайт (число, текст), тоже даёт ошибку `object`.
- Одновременно может быть не больше **128 живых спрайтов**; программа без `DO … LOOP` может ещё и создать не больше **512** за всё время. Любое превышение — ошибка `limit`.
- `CLS` не убирает спрайты. СБРОС или начало запуска — убирает.
- Вызовы методов — это операторы: `CAT.MOVE 10,20`. Свойства — значения: `X = CAT.X`.

## Функции

### `SPAWN` {#fn-spawn}

**Синтаксис:** `переменная = SPAWN(имя, x, y)` · функция, возвращающая спрайт.

Создаёт видимый спрайт в `x,y`. `имя` — идентификатор встроенного спрайта (см. [ресурсы](book:ref-assets); регистр не важен) или `@псевдоним` спрайта, сохранённого в проекте. Неизвестное имя — ошибка `sprite`, которая перечисляет допустимые. `x` и `y` должны быть в пределах ±10 000.

```basic id=r-spawn sprites=1 events=SPAWN:cat
CAT = SPAWN("cat",128,100)
```

### `HIT` {#fn-hit}

**Синтаксис:** `HIT(a, b)` → `TRUE` или `FALSE`

`TRUE`, когда два спрайта перекрываются. Оба должны быть живыми и **видимыми**. Каждый спрайт считается прямоугольником `WIDTH` × `HEIGHT` с центром в его позиции; прямоугольники перекрываются, когда расстояние по горизонтали между центрами меньше половины суммы ширин **и** расстояние по вертикали меньше половины суммы высот. Спрайты, которые лишь касаются краями, не перекрываются. Если передать не спрайты, будет ошибка `object`.

```basic id=r-hit output="true|false"
A = SPAWN("cat",50,50)
B = SPAWN("star",60,55)
PRINT HIT(A,B)
B.HIDE
PRINT HIT(A,B)
```

## Методы

### `.SIZE` {#method-size}

**Синтаксис:** `спрайт.SIZE ширина,высота` · целые числа; ширина 1–256, высота 1–192 (иначе `range`).

Меняет нарисованный размер и рамку для попаданий. Поворот и движение продолжают работать.

```basic id=r-size vars="W=40;H=10"
BAR = SPAWN("paddle",128,170)
BAR.SIZE 40,10
W = BAR.WIDTH
H = BAR.HEIGHT
```

### `.MOVE` {#method-move}

**Синтаксис:** `спрайт.MOVE x,y`

Ставит центр в `x,y`. Координаты за пределами ±10 000 дают `range`. Ограничения экраном нет: спрайт можно убрать за пределы ЭКРАНА и вернуть.

### `.MOVE_BY` {#method-move-by}

**Синтаксис:** `спрайт.MOVE_BY dx,dy`

Сдвигает спрайт на указанную величину от нынешнего места: `dx` вправо, `dy` вниз (отрицательные значения — влево и вверх).

```basic id=r-move vars="PX=70;PY=50"
S = SPAWN("star",10,20)
S.MOVE 50,30
S.MOVE_BY 20,20
PX = S.X
PY = S.Y
```

### `.TURN` {#method-turn}

**Синтаксис:** `спрайт.TURN градусы`

Задаёт поворот в градусах (по часовой стрелке, вокруг центра). Значение берётся по модулю 360 и является абсолютным, а не добавочным: два вызова `TURN 90` подряд — всё те же 90.

```basic id=r-turn sprites=1
R = SPAWN("rocket",128,100)
R.TURN 90
```

### `.SHOW` {#method-show}

**Синтаксис:** `спрайт.SHOW` · снова делает спрятанный спрайт видимым. На видимый не действует.

### `.HIDE` {#method-hide}

**Синтаксис:** `спрайт.HIDE` · прячет спрайт. Он остаётся живым: сохраняет позицию, его можно двигать и о нём можно спрашивать, но он не рисуется, а `HIT` его игнорирует.

```basic id=r-hide output="false|true"
G = SPAWN("ghost",100,100)
G.HIDE
PRINT G.VISIBLE
G.SHOW
PRINT G.VISIBLE
```

### `.DESTROY` {#method-destroy}

**Синтаксис:** `спрайт.DESTROY`

Убирает спрайт насовсем. После этого можно читать только `.ALIVE`; он равен `FALSE`.

### `.SAY` {#method-say}

**Синтаксис:** `спрайт.SAY текст`

Показывает над спрайтом облачко с первыми **40** символами `текст`. Пустая строка `""` убирает облачко. Оно держится, пока ты его не изменишь.

### `.EXPLODE` {#method-explode}

**Синтаксис:** `спрайт.EXPLODE` · **Блокирует** примерно на полсекунды.

Драматичный взрыв: спрайт показывает `!`, ждёт 0,2 секунды, играет звук взрыва, а затем **уничтожает каждый спрайт в радиусе 44 пикселей** (и себя тоже) и стирает нарисованные фигуры и пиксели в том же радиусе. Ещё несколько кадров летят искры. Считается за одно звуковое событие.

```basic id=r-explode sprites=0 px="100,100=8"
INK 2
FILLBOX 90,90,20,20
B = SPAWN("dynamite",100,100)
B.EXPLODE
```

## Свойства

Читай их везде, где допустимо значение: `IF CAT.X > 200 THEN`.

### `.X` `.Y` {#prop-x}

Текущая позиция центра (числа). `X` равно 0 у левого края, `Y` равно 0 у верхнего.

### `.VISIBLE` {#prop-visible}

`TRUE`, если спрайт не был спрятан.

### `.WIDTH` `.HEIGHT` {#prop-size}

Размер, используемый для проверки попаданий: 16, пока не вызван `SIZE`. У собственных спрайтов они тоже начинаются с 16 (см. факты выше).

### `.ALIVE` {#prop-alive}

`TRUE`, пока спрайт не уничтожен. Единственное свойство, которое можно прочитать у уничтоженного спрайта.

```basic id=r-props output="12|20|true|true"
S = SPAWN("slime",12,20)
PRINT S.X
PRINT S.Y
PRINT S.VISIBLE
PRINT S.ALIVE
```
