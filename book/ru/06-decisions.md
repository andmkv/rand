# Решения, вопросы и ошибки

**Цель:** научить программу выбирать между действиями, спрашивать игрока и понимать, что говорит машина, когда что-то пошло не так.

## IF … THEN … END IF

`IF` выполняет своё тело только тогда, когда условие истинно.

```basic id=c06-if output="Высокий счёт!"
SCORE = 7
IF SCORE > 5 THEN
  PRINT "Высокий счёт!"
END IF
```

Форма всегда одна и та же:

```text
IF условие THEN
  ...операторы, которые выполняются, если условие истинно...
END IF
```

`THEN` должно быть последним на своей строке, а тело идёт на следующих строках. Однострочной формы `IF` нет. Всё до `END IF` относится к условию.

## Сравнения

**Условие** — это вопрос с ответом «да» или «нет». Его строят из сравнения:

| Запись | Значит |
| --- | --- |
| `A = B` | A равно B |
| `A <> B` | A *не* равно B |
| `A < B` / `A > B` | A меньше / больше B |
| `A <= B` / `A >= B` | A меньше или равно / больше или равно B |

Заметь, что `=` значит две разные вещи. В начале строки `SCORE = 7` *сохраняет* 7 в SCORE. Внутри `IF` запись `SCORE = 7` *спрашивает*, равно ли SCORE семи.

Текст тоже можно сравнивать на равенство: `IF NAME = "Мия" THEN`. Знаки `<`, `>`, `<=` и `>=` работают **только с числами**. Число и строка никогда не равны, так что `1 = "1"` — ложь.

## ELSE: иначе

Добавь `ELSE`, чтобы что-то выполнялось, когда условие ложно.

```basic id=c06-else output="Продолжай!"
SCORE = 3
IF SCORE > 5 THEN
  PRINT "Высокий счёт!"
ELSE
  PRINT "Продолжай!"
END IF
```

`ELSE IF` не существует. Чтобы проверить несколько вещей подряд, вложи ещё один `IF` в `ELSE`:

```basic id=c06-grades output="Бронза"
POINTS = 40
IF POINTS >= 90 THEN
  PRINT "Золото"
ELSE
  IF POINTS >= 70 THEN
    PRINT "Серебро"
  ELSE
    PRINT "Бронза"
  END IF
END IF
```

У каждого `IF` свой `END IF`. Главное умение — подбирать их друг к другу, как скобки: вложенный `IF` с отступом в два пробела читать намного легче.

## AND, OR, NOT

Соединяем условия:

- `A AND B` истинно, только когда истинны **оба**.
- `A OR B` истинно, когда истинно **хотя бы одно** (или оба).
- `NOT A` меняет истину на ложь и ложь на истину.

```basic id=c06-logic output="внутри|снаружи"
X = 100
Y = 50
IF X > 80 AND X < 180 AND Y > 20 AND Y < 100 THEN
  PRINT "внутри"
END IF
X = 250
IF X < 10 OR X > 245 THEN
  PRINT "снаружи"
END IF
```

`AND` выполняется раньше `OR`, как умножение раньше сложения, а `NOT` — раньше `AND`. Если сомневаешься, поставь скобки: `(A OR B) AND C`.

Правая часть `AND` или `OR` пропускается, если ответ уже понятен. Например, `FALSE AND ЧТО_УГОДНО` ложно, даже не заглядывая в `ЧТО_УГОДНО`.

> [!NOTE]
> Ответ «да/нет» можно хранить в переменной: `ALIVE = TRUE`, а затем `IF ALIVE THEN`. Слова `TRUE` и `FALSE` встроены. Для удобства `IF` ещё и считает ложью число `0` и пустую строку `""`, а всё остальное — истиной. Это правило верное, но легко понять неправильно, поэтому для читаемости пиши явное сравнение, например `IF LIVES > 0 THEN`.

## Картинка, которая принимает решения

```basic id=c06-checker px="4,4=15;28,4=0;4,28=0;28,28=15"
FOR Y = 0 TO 7
  FOR X = 0 TO 7
    IF (X + Y) / 2 = ROUND((X + Y) / 2) THEN
      INK 7
    ELSE
      INK 0
    END IF
    FILLBOX X * 24, Y * 24, 24, 24
  NEXT X
NEXT Y
```

Условие спрашивает, целое ли число `(X + Y) / 2`; это верно, когда X + Y чётно. Так программа отличает чётное от нечётного без всякой специальной команды: раздели пополам, округли и посмотри, изменилось ли что-нибудь.

## INPUT: задаём вопрос

`INPUT "вопрос", ИМЯ` показывает вопрос и ждёт, пока игрок напечатает ответ. Программа стоит, пока он не нажмёт Enter.

```basic id=c06-input input="Мия|4" output="Привет, Мия!|Ты сказал 4|Хороший выбор."
INPUT "Как тебя зовут?", NAME
PRINT "Привет, " + NAME + "!"
GUESS = 0
INPUT "Выбери число от 1 до 5", GUESS
PRINT "Ты сказал " + GUESS
IF GUESS > 3 THEN
  PRINT "Хороший выбор."
END IF
```

Есть одна ловушка, которую стоит запомнить: **какого вида получится ответ?** Если в переменной уже лежит *число*, ответ должен быть числом и сохраняется числом. Если переменная пустая или в ней текст, ответ сохраняется как текст. Поэтому программа сначала ставит `GUESS = 0`, говоря машине: «здесь я жду число». Если потом кто-то напечатает буквы, машина скажет *Введи число для GUESS.*

Текст вопроса — обычное значение, так что `"Привет, " + NAME + ", выбери число"` тоже подойдёт в качестве вопроса.

## Когда что-то пошло не так

Ошибки делают все, и профессионалы тоже; уметь читать сообщения — это навык. Машина называет **номер строки** и простыми словами говорит, чего она ждала.

```basic id=c06-error-name error=variable
PRINT SCORE
```

*Строка 1: Сначала присвой SCORE значение.* Переменной `SCORE` никогда не давали значения.

Если ошибиться в названии команды, машина подскажет:

```basic id=c06-error-typo error=unknown
CIRCL 128,96,20
```

*Строка 1: Я не знаю заклинания CIRCL. Ты имел в виду CIRCLE?*

Самые частые причины ошибок в том порядке, в каком ты, скорее всего, с ними встретишься:

1. **Опечатка**: `CIRCL`, `FILBOX`, `PRNT`. Сверь написание с Книгой заклинаний.
2. **Не хватает значения**: переменную прочитали раньше, чем присвоили, или команде дали слишком мало чисел (*Для CIRCLE нужно 3 ингредиентов*).
3. **Не хватает конца**: `IF` без `END IF`, `FOR` без `NEXT`, `DO` без `LOOP`. В сообщении сказано, чего именно.
4. **Не хватает кавычки**: `"HELLO` вместо `"HELLO"`.
5. **Число вне диапазона**: `INK 9`, `RND(5,1)`, координаты больше ±10000.

Полный перечень — в разделе [Сообщения об ошибках](book:ref-errors).

### Отладка через PRINT

Если программа работает, но делает что-то странное, спроси у машины, о чём она думает. Поставь `PRINT` в тех местах, где сомневаешься, запусти и прочитай значения. Когда ошибка найдена, удали лишние `PRINT`.

## Попробуй

1. Сделай так, чтобы проверка «внутри» рисовала на ЭКРАНЕ рамку, а не печатала слово.
2. Спроси у игрока число и напечатай `"чётное"` или `"нечётное"`. Используй приём «раздели и округли».
3. Игра «Загадай число»: `SECRET = RND(1,5)`, спроси догадку и напечатай, мала она, велика или верна. (Потом загляни в ПРИМЕРЫ — там есть *Волшебник чисел*.)

## Что ты узнал

- `IF … THEN … ELSE … END IF` выбирает; сравнения — `= <> < > <= >=`.
- `AND`, `OR`, `NOT` соединяют условия.
- `INPUT` спрашивает; начальное значение переменной определяет, будет ответ числом или текстом.
- В сообщениях об ошибках назван номер строки и сказано, чего ждали. `PRINT` — твой фонарик.
