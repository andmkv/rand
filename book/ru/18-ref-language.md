# Справочник: язык

Это точное описание диалекта BASIC, который запускает Randomize USR. Оно составлено по исходному коду интерпретатора и проверяется тестами руководства: у каждой команды, которую знает машина, есть раздел на страницах справочника, и каждый пример здесь запускается. За более мягкими объяснениями обращайся к главам; сюда приходи, чтобы что-то уточнить.

**Как читать статью справочника.** Квадратные скобки `[вот так]` означают необязательную часть. Слово строчными (`x`, `seconds`) обозначает значение, которое ты подставляешь. В руководстве команды пишутся заглавными, но машине регистр безразличен.

## Программы и строки

Программа — это простой текст до **100 000 символов**. Она читается построчно, и **каждый оператор стоит на своей строке**. Нельзя поставить два оператора на одну строку (нет `:`) и нельзя продолжить оператор на следующей строке.

Оператор — это одно из:

| Форма | Пример |
| --- | --- |
| присваивание | `SCORE = SCORE + 1` или `LET SCORE = 1` |
| команда | `CIRCLE 128,96,20` |
| вызов метода спрайта | `CAT.MOVE_BY 2,0` |
| `INPUT` | `INPUT "Name?", NAME` |
| блок | `FOR … NEXT`, `IF … END IF`, `DO … LOOP`, `SUB … END SUB` |
| выход из цикла или SUB | `EXIT DO`, `EXIT FOR`, `EXIT SUB` |
| вызов SUB | `CALL DRAW_TREE` |

Пустые строки и отступы игнорируются. Функция, которая возвращает значение (`SPAWN`, `RND`…), не может стоять отдельным оператором; её значение надо куда-то положить: `CAT = SPAWN("cat",10,10)`.

## Имена

**Имя** (переменной) начинается с буквы (любого алфавита) или `_`, затем идут буквы, диакритические знаки, цифры или `_`; не больше **64 символов**. Регистр в именах **не важен**: `Score`, `SCORE` и `score` — одна переменная. Переменные не нужно объявлять: они создаются присваиванием. Чтение переменной без значения даёт ошибку `variable`. **Все переменные очищаются в начале каждого ЗАПУСКА.** Переменные глобальные: `SUB` видит и меняет те же самые переменные, что и остальная программа, а локальных переменных нет.

Не используй слова языка в качестве имён переменных (`IF`, `FOR`, `NEXT`, `TO`, `STEP`, `THEN`, `ELSE`, `END`, `DO`, `LOOP`, `EXIT`, `SUB`, `CALL`, `MOD`, `AND`, `OR`, `NOT`, `LET`, `TRUE`, `FALSE`, `INPUT`, `REM`). Названия команд и функций (например, `SIZE` или `TEXT`) случайно тоже подходят как имена переменных, но это сбивает с толку.

## Значения

| Вид | Как пишется | Примечания |
| --- | --- | --- |
| число | `42`, `3.5`, `.5` | Только десятичные цифры; без экспоненты (`1E3`) и без шестнадцатеричной записи. Всегда конечное. Допустим ведущий `-` или `+`. |
| строка | `"текст"` | Только двойные кавычки. Без escape-последовательностей: в строке не может быть `"`, и она не может занимать несколько строк кода. До **2000** символов. |
| логическое | `TRUE`, `FALSE` | Также результат любого сравнения. |
| спрайт | из `SPAWN` | Объект с положением; см. [спрайты](book:ref-sprites). |
| список | из `LIST(…)` | Упорядоченный ряд значений; см. [списки](book:ref-lists). |

`PRINT` показывает логическое значение как `true` или `false`, число — так, как это сделал бы JavaScript (поэтому `1/3` — это `0.3333333333333333`), а строку — как есть.

## Операторы и приоритеты

От самого слабого к самому сильному:

| Уровень | Операторы |
| --- | --- |
| 1 | `OR` |
| 2 | `AND` |
| (префиксный) | `NOT` — относится к сравнению после него |
| 3 | `=` `<>` `<` `>` `<=` `>=` |
| 4 | `+` `-` |
| 5 | `*` `/` `MOD` |
| (префиксный) | унарные `-` и `+` — самые сильные |

Операторы одного уровня группируются слева. Скобки `( )` перекрывают всё. Сравнения не образуют цепочек: `1 < 2 < 3` — это `(1 < 2) < 3`, а это ошибка, потому что `TRUE` — не число.

`AND` и `OR` всегда дают `TRUE` или `FALSE` и пропускают правую часть, если левая уже решает результат (`FALSE AND X` даже не смотрит на `X`).

Условие (в `IF`) истинно, если оно не `FALSE`, не число `0` и не пустая строка. Это удобство верное, но легко понять неверно; лучше пиши явные сравнения.

```basic id=r-precedence output="14|true|true|false"
PRINT 2 + 3 * 4
PRINT 2 + 3 * 4 = 14 AND NOT 2 = 3
PRINT TRUE OR MISSING
PRINT FALSE AND MISSING
```

## Комментарии

### `REM` {#kw-rem}

```text
REM что угодно до конца строки
' тоже комментарий
```

Оба начинают комментарий, идущий до конца строки: на отдельной строке или после оператора. `REM` должно быть целым словом (так что `REMIX = 3` — присваивание). Комментарии игнорируются.

```basic id=r-rem output="готово"
REM Ставим точку посередине
PLOT 128,96 ' жёлтая точка потребовала бы сначала INK 6
PRINT "готово"
```

### `LET` {#kw-let}

**Синтаксис:** `[LET] имя = значение`

`LET` необязателен и ничего не меняет. `LET X = 5` значит ровно то же, что `X = 5`.

## Циклы

### `FOR` `NEXT` `STEP` `TO` {#kw-for}

**Синтаксис:** `FOR имя = начало TO конец [STEP шаг]` … `NEXT [имя]`

Присваивает `имя` значение `начало`, выполняет тело, прибавляет `шаг` (по умолчанию `1`) и повторяет, пока значение не перешагнуло `конец`. Отрицательный `STEP` считает вниз (цикл идёт, пока `имя >= конец`). Три числа вычисляются один раз, перед первым проходом. `STEP 0` — ошибка (`step`). Счётчик — обычная переменная, и после цикла она хранит значение с последнего прохода. Если после `NEXT` написано имя, это должна быть та же переменная.

Один `FOR` выполняет не больше **10 000 проходов** (после этого ошибка `limit`). Циклы можно вкладывать до 40 уровней.

```basic id=r-for output="1|3|5|3|2|1"
FOR I = 1 TO 5 STEP 2
  PRINT I
NEXT I
FOR J = 3 TO 1 STEP -1
  PRINT J
NEXT J
```

### `DO` `LOOP` {#kw-do}

**Синтаксис:** `DO` … `LOOP`

Повторяет своё тело, пока ты не нажмёшь СТОП, не случится ошибка или тело не выполнит [`EXIT DO`](#kw-exit). Программа, в которой `DO` встречается где угодно, считается долго работающей: общие ограничения на операторы, проходы циклов и две минуты на неё не действуют. Поставь внутрь `FRAME` или `WAIT`, чтобы цикл отдавал время.

```basic id=r-do endless wait=2 vars="N>10"
N = 0
DO
  N = N + 1
  WAIT 0.05
LOOP
```

### `EXIT` {#kw-exit}

**Синтаксис:** `EXIT DO` · `EXIT FOR` · `EXIT SUB`

Досрочно выходит из блока. `EXIT DO` выпрыгивает из ближайшего окружающего `DO … LOOP`, `EXIT FOR` — из ближайшего окружающего `FOR … NEXT`, а `EXIT SUB` заканчивает `SUB`, в котором стоит. Программа продолжается со строки после блока (после `EXIT SUB` — со строки после `CALL`). `EXIT DO` работает и из `FOR`, который лежит внутри `DO`, и наоборот.

Нужный блок должен существовать: `EXIT DO` без окружающего `DO … LOOP` (в том же `SUB` или в основной программе) — ошибка ещё до запуска; так же `EXIT FOR` без `FOR` и `EXIT SUB` вне `SUB`. Из `SUB` нельзя выйти через циклы того кода, который его вызвал.

После `EXIT DO` программа всё равно считается долго работающей, потому что в ней есть `DO`.

```basic id=r-exit-do output="1|2|3|done"
N = 0
DO
  N = N + 1
  PRINT N
  IF N = 3 THEN
    EXIT DO
  END IF
LOOP
PRINT "done"
```

```basic id=r-exit-for output="11|21"
FOR A = 1 TO 2
  FOR B = 1 TO 5
    IF B = 2 THEN
      EXIT FOR
    END IF
    PRINT A * 10 + B
  NEXT B
NEXT A
```

Внутренний `EXIT FOR` выходит только из внутреннего цикла; внешний `FOR A` продолжается.

## Подпрограммы

### `SUB` `CALL` `END SUB` {#kw-sub}

**Синтаксис:**

```text
SUB ИМЯ
  операторы
END SUB

CALL ИМЯ
```

`SUB` — это часть программы с именем. Когда машина читает его, ничего не происходит; операторы выполняются каждый раз, когда доходит очередь до строки `CALL ИМЯ`, а потом программа идёт дальше после этого `CALL`.

- `SUB` пишется на **верхнем уровне** программы, не внутри `FOR`, `IF`, `DO` и не внутри другого `SUB`. Он может стоять до или после `CALL`, который его использует.
- Имя подчиняется правилам имён переменных; `SUB` и переменная с одним именем друг другу не мешают. Два `SUB` с одним именем — ошибка.
- У `SUB` **нет ингредиентов**, и он ничего не возвращает. Все переменные у него общие с остальной программой: чтобы что-то передать, задай переменную заранее; чтобы получить результат, прочитай переменную после.
- `EXIT SUB` заканчивает `SUB` раньше. `SUB` может вызывать другой `SUB` и даже самого себя, но не больше **32** вызовов один внутри другого; более глубокая цепочка — ошибка `limit` («Вот это много магии!»).
- `CALL` имени, которого нет ни у одного `SUB`, — ошибка ещё до запуска, с подсказкой «Ты имел в виду …?».
- `SUB`, в котором есть `FRAME`, `DO` или `WAIT`, ведёт себя так же, как те же строки в основной программе: программа, где `DO` встречается где угодно, даже внутри `SUB`, считается долго работающей.

```basic id=r-sub output="5|10|done"
SCORE = 0
SUB SCORED
  SCORE = SCORE + 5
  PRINT SCORE
END SUB
CALL SCORED
CALL SCORED
PRINT "done"
```

```basic id=r-sub-exit output="start|end"
SUB CHECK
  PRINT "start"
  IF TRUE THEN
    EXIT SUB
  END IF
  PRINT "never printed"
END SUB
CALL CHECK
PRINT "end"
```

## Решения

### `IF` `THEN` `END IF` `END` {#kw-if}

**Синтаксис:**

```text
IF условие THEN
  операторы
[ELSE
  операторы]
END IF
```

`THEN` должно быть последним на своей строке, а тело начинается со следующей; однострочного `IF` нет. `END IF` — два слова. `ELSEIF` нет; вкладывай `IF` внутрь `ELSE`. Блоки можно вкладывать на глубину 40. `END` допустимо только как первая половина `END IF` или `END SUB`; само по себе оно — ошибка, потому что программу нельзя завершить досрочно.

```basic id=r-if output="B"
SCORE = 70
IF SCORE >= 90 THEN
  PRINT "A"
ELSE
  IF SCORE >= 60 THEN
    PRINT "B"
  ELSE
    PRINT "C"
  END IF
END IF
```

### `ELSE` {#kw-else}

Начинает вторую ветку `IF`. Должно стоять на отдельной строке, один раз на `IF`. См. `IF`.

## Логика

### `AND` `OR` `NOT` {#kw-logic}

`a AND b` истинно, когда истинны оба; `a OR b` — когда истинно хотя бы одно; `NOT a` переворачивает. См. таблицу приоритетов выше. `AND` и `OR` пропускают правую часть, если левая уже решает результат.

```basic id=r-logic output="true|false|true"
PRINT 5 > 3 AND 2 < 4
PRINT NOT TRUE
PRINT 1 = 2 OR 3 = 3
```

## Арифметика и сравнения

### `+` `-` `*` `/` {#op-arithmetic}

Числа складываются, вычитаются, умножаются и делятся по обычным приоритетам. `+` ещё и **склеивает** текст: если с любой стороны строка, обе стороны превращаются в текст и склеиваются (длина склеенного результата ограничена 2000 символами). Деление на ноль — ошибка `zero`. Вычитание, умножение или деление чего-либо, что не число, — ошибка `number`.

```basic id=r-arithmetic output="7|-1|12|2.5|ab|a1|3 apples"
PRINT 3 + 4
PRINT 3 - 4
PRINT 3 * 4
PRINT 5 / 2
PRINT "a" + "b"
PRINT "a" + 1
PRINT 3 + " apples"
```

### `=` `<>` `<` `>` `<=` `>=` {#op-compare}

`=` и `<>` (не равно) сравнивают любые два значения одного вида; значения разных видов никогда не равны (`1 = "1"` — это `FALSE`). Сравнение текста учитывает регистр. Спрайты и списки равны только самим себе. `<`, `>`, `<=` и `>=` требуют чисел.

```basic id=r-compare output="true|false|true|false"
PRINT 3 <> 4
PRINT "Cat" = "cat"
PRINT 2 <= 2
PRINT 1 = "1"
```
