# Столкновения, счёт и состояния игры

**Цель:** знать, когда две вещи соприкоснулись, считать очки и обрабатывать победу, поражение и новую попытку.

## HIT: касаются ли эти двое?

`HIT(a,b)` отвечает `TRUE`, когда два спрайта перекрываются. Оба спрайта должны быть живыми и видимыми. Сравниваются их **рамки**: каждый спрайт считается прямоугольником `WIDTH` × `HEIGHT` с центром в его позиции.

```basic id=c12-hit output="true|false|true|false"
A = SPAWN("cat",100,100)
B = SPAWN("star",110,100)
PRINT HIT(A,B)
B.MOVE 140,100
PRINT HIT(A,B)
B.MOVE 115,100
PRINT HIT(A,B)
B.MOVE 116,100
PRINT HIT(A,B)
```

Оба спрайта шириной 16 пикселей. Они перекрываются, пока расстояние между центрами меньше 16 пикселей, а при ровно 16 просто *касаются краями*, и это не считается. Поэтому последний ответ — `false`.

### Подгони рамку под картинку

Рамка — это грубое представление формы. У высокого узкого персонажа рамка должна быть высокой и узкой:

```basic id=c12-size vars="W=12;H=16" sprites=1
HERO = SPAWN("traveler",50,50)
HERO.SIZE 12,16
W = HERO.WIDTH
H = HERO.HEIGHT
```

`SIZE` меняет и то, что ты видишь, и то, что измеряет `HIT`. Сделай пулю узкой: `SHOT.SIZE 3,8`. Сделай ракетку широкой: `PADDLE.SIZE 40,8`. В некоторых играх рамка чуть меньше картинки, чтобы «почти попал» был честным.

## Поймать что-нибудь

Двигай один спрайт, пока он не коснётся другого, и реагируй. Здесь звезда падает на кота по три пикселя за кадр:

```basic id=c12-catch output="Поймано! Кадров: 52" sprites=1
CAT = SPAWN("cat",128,170)
STAR = SPAWN("star",128,0)
FOR T = 1 TO 100
  IF STAR.ALIVE THEN
    STAR.MOVE_BY 0,3
    IF HIT(CAT,STAR) THEN
      PRINT "Поймано! Кадров: " + T
      SFX "coin"
      STAR.DESTROY
    END IF
  END IF
  FRAME
NEXT T
```

Здесь заметны две подробности. `STAR.DESTROY` убирает звезду, поэтому сообщение появляется один раз; иначе звезда ещё несколько кадров перекрывала бы кота, и сообщение повторялось бы. А когда спрайт уничтожен, любой приказ ему (`STAR.MOVE_BY`) — ошибка, поэтому программа сначала спрашивает `STAR.ALIVE`. `ALIVE` — единственное свойство, о котором можно спросить всегда.

В настоящей игре цикл — это `DO … LOOP`, который сам никогда не заканчивается. Что происходит внутри, решают *переменные состояния*, как показано в следующем разделе.

## Состояния игры

Игра находится в одной ситуации за раз: готовится, идёт, выиграна, проиграна. Назови эти ситуации числом в переменной, обычно `STATE`, и сделай так, чтобы каждая часть цикла зависела от неё. Все три игры, которые идут с машиной (*Атака пришельцев*, *Разбей кирпичи* и *Пиксельный поход*), используют такие четыре:

| STATE | Значение |
| --- | --- |
| 0 | подготовить новую игру |
| 1 | игра идёт |
| 2 | выиграно |
| 3 | проиграно |

```basic id=c12-states endless wait=6 vars="STATE>=1;STATE<=2"
CAT = SPAWN("cat",128,170)
STAR = SPAWN("star",128,0)
STATE = 0
DO
  IF STATE = 0 THEN
    SCORE = 0
    STAR.MOVE 128,0
    STAR.SHOW
    STATE = 1
  END IF
  IF STATE = 1 THEN
    STAR.MOVE_BY 0,3
    IF HIT(CAT,STAR) THEN
      SCORE = SCORE + 1
      STAR.MOVE 128,0
      SFX "coin"
    END IF
    IF SCORE = 3 THEN
      STATE = 2
    END IF
  END IF
  CLS 1
  INK 6
  TEXT 6,4,"SCORE " + SCORE
  IF STATE = 2 THEN
    INK 4
    TEXT 90,90,"YOU WIN!"
  END IF
  FRAME
LOOP
```

Читай как рассказ: блок `STATE = 0` выполняется один раз, готовит игру и переходит в состояние 1. Состояние 1 играет и решает, когда перейти в состояние 2. После этого цикл снова и снова рисует надпись «YOU WIN!», пока ты не нажмёшь СТОП. Чтобы начать заново, нужно снова поставить `STATE = 0`, что и добавляется в следующем разделе.

> [!TIP]
> Обрати внимание на порядок внутри цикла: сначала меняем **состояние**, потом **рисуем**. Если рисовать последним, картинка всегда соответствует текущему состоянию, без наполовину обновлённых кадров.

## Счёт, нарисованный заново на каждом кадре

Рисунки сами не обновляются. Надпись «SCORE 2» остаётся, пока что-нибудь не нарисует поверх. Есть два распространённых способа:

1. **Стереть, потом написать** (нужно, когда не очищаешь весь экран): нарисуй закрашенный прямоугольник цвета фона, а затем текст.
2. **Перерисовывать всё на каждом кадре**: так делают игры из комплекта. Начни часть цикла, которая рисует, с `CLS 1` (или `CLS 0`), а затем снова нарисуй название, счёт и сообщения. Спрайты `CLS` не трогает.

Способ 2 проще и надёжнее: экран на каждом кадре собирается заново из переменных. Поскольку в программе есть `FRAME`, машина позволяет рисовать много вещей за кадр без замедления.

Помни про приём склеивания текста и чисел: `"SCORE " + SCORE`.

## Начать сначала

Добавь проверку `KEY("R")` в начало цикла. Если игра окончена (`STATE > 1`), нажатие R возвращает её в состояние 0, которое всё подготавливает заново:

```basic id=c12-restart endless wait=3 keys=R vars="STATE>=1"
STATE = 3
DO
  IF KEY("R") AND STATE > 1 THEN
    STATE = 0
  END IF
  IF STATE = 0 THEN
    STATE = 1
  END IF
  CLS 0
  INK 7
  IF STATE = 1 THEN
    TEXT 80,90,"PLAYING"
  ELSE
    TEXT 64,90,"PRESS R TO RESTART"
  END IF
  FRAME
LOOP
```

Эта программа стартует в состоянии «проиграно», чтобы ты увидел, как всё работает. Нажми R, и она переключится на «игру».

## Попробуй

1. Пусть звезда даёт 10 очков за поимку, а итог печатается как `SCORE 30`.
2. Добавь счётчик `LIVES`, который уменьшается, когда звезда падает ниже дна.
3. Добавь рекорд: храни `BEST` и обновляй его, когда `SCORE` больше. Помни, что ЗАПУСК обнуляет все переменные, а перезапуск внутри цикла — нет.

<details>
<summary>Подсказки и ответы</summary>

1. `SCORE = SCORE + 10` и `IF SCORE = 30 THEN`.
2. `IF STAR.Y > 192 THEN LIVES = LIVES - 1` (в несколько строк) и `IF LIVES = 0 THEN STATE = 3`. Следующая глава строит из этого настоящую игру.
3. Поставь `BEST = 0` один раз перед `DO`. Когда игра заканчивается: `IF SCORE > BEST THEN BEST = SCORE` в несколько строк.

</details>

## Что ты узнал

- `HIT(a,b)` проверяет пересечение рамок; `SIZE` задаёт рамку.
- Переменная `STATE` превращает цикл в маленький автомат: подготовка, игра, победа, поражение.
- Перерисовывай текст интерфейса на каждом кадре через `CLS` и `TEXT`; для перезапуска используй клавишу.
